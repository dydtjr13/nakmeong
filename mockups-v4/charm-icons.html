🧿 행운 부적 아이템 이미지 시안 (게임 미적용)

현재 게임은 모든 부적이 같은 아이콘 → 옵션별 / 등급별로 한눈에 구분되도록 4가지 방식 제안. 등급 색: 일반 회색 · 고급 초록 · 희귀 파랑 · 영웅 장미 · 전설 금 · 신화 보라

세트 A · 옵션별 아이콘 (9종) 추천: 주 옵션 표시용

부적의 첫 번째(가장 높은) 옵션 아이콘을 사용. 등급은 카드 테두리 색으로 표시

세트 B · 등급별 복주머니 (6단계)

한국적 복주머니 + 물고기 자수. 등급이 오를수록 비단·금사·보석·홀로그램

세트 C · 등급별 잉어 메달리온 (6단계)

강돌 → 옥 → 사파이어 → 루비 → 호박 → 오팔. 전설·신화는 후광

세트 D · 조합형 (등급 메달리온 + 옵션 문양) 최종 추천

세트 C 프레임 위에 세트 A의 옵션 문양을 얹음 → 등급과 주 옵션을 동시에 표현 (예: 6등급 × 9옵션 = 54 조합을 이미지 15장으로)
