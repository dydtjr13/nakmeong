요약

  1. 튜토리얼 완수해도 안 넘어가던 버그 수정 + 50단계 (초반 즉시 가능 위주)
  2. 보상 미지급 수정 — 완수→보상→다음이 한 흐름
  3. 설정에서 튜토리얼 임무 지정(점프/다음/완료/끄기/처음부터)
  4. 솔로 로컬 저장 — 같은 브라우저 재접속 시 유지

1) 튜토리얼 버그 원인

증상 원인 수정
앉아도 미완료 goal.seat가 nearSpot()만 검사 → 벤치/일반 좌석이면 실패 mySeat()로 검사
상점 판매해도 미완료 상점/어항 판매 시 S.earned 미증가 판매 경로에 S.earned+=
장비 임무 불가 보상이 장비인데 목표가 장착 → 닭-달걀 스텝 입장 시 grant로 선지급 → 장착 목표
보상 안 들어옴 / 중복·누락 give 후 인덱스만 증가, 실패 시 침묵 · 재진입 시 재지급 위험 P.paid[id] / P.granted[id]로 1회 보장, complete()에서 지급→저장→다음
고레벨 즉시 스킵 lv>=5 또는 caught>=30이면 전체 스킵 lv>=10 그리고 caught>=80으로 완화

2) 보상 흐름 (검증)

목표 달성 → complete(st)
  → give(st.rw)  (paid[id]로 1회)
  → toast 완료+보상
  → P.i++ / baseline 리셋
  → 다음 스텝 grant(있으면)
  → render

테스트 t80: - hello 완료 → 코인 +30, paid.hello=1, i=1 - wearHat: grant로 모자 지급 → 장착 → 완료 보상 +80, 모자 유지 - sell 완료 → 보상 +120 - STEPS.length = 50

3) 50개 임무 요약

  • 1~12 즉시: 인사 탭, 앉기, 낚시버튼, 첫낚시, 가방/상점/어항/도감/설정 열기, 3마리, 떡밥, 판매
  • 13~16 장비: 모자·티·짚신·장갑 (선지급 후 장착)
  • 17~30 가벼운 성장: 도감3~7, 낚시 추가, Lv2~4, 상자·강화석(선지급 포함)
  • 31~50 점진: Lv5~10, 도감10~15, 코인·낚시량 증가, 졸업 Lv10

고레벨·장시간만 요구하던 단일 벽은 초반에서 제거하고, 뒤로 갈수록만 난이도↑.

4) 설정 UI

설정 › 튜토리얼: - 스타일/위치 셀렉트 (기존) - 임무 드롭다운 + 이 임무로 이동 / 다음 / 모두 완료 / 처음부터 / 숨기기(끄기) - 관리자 패널의 튜토리얼 버튼도 유지
