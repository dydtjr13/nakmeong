# 피쉬레스트 v25 보고서

시안 모음: [mockups-v25](../mockups-v25/) · 단계별 커밋: 1단계 버그 → 2단계 UI → 3단계 관리자 → 4단계 시안 → 5단계 보고서·배포

## 1. 게임에 적용한 것

| 번호 | 내용 | 결과 |
|---|---|---|
| 1 | 신화·초월 컷인 화면 이상 | **원인:** 화면 흔들기를 `body` 전체에 걸어서, 고정 위치 UI(상단바·메뉴·채팅 등)가 통째로 흔들리고 다시 그려졌어요. **수정:** 3D 화면(캔버스)만 흔들어요. 초월 컷인도 같은 원인이라 같이 고쳤어요. 설정 › 디버그와 관리자 › 테스트에 **초월 컷인 테스트** 버튼을 넣었어요 |
| 2 | 날씨 카드 정렬 | PC는 낚시 정보 줄과 왼쪽·폭이 같아요. 모바일은 코인 칸부터 메뉴 버튼까지 폭이 같아요. 위 창과의 간격은 레벨창↔정보줄 간격보다 2px 넓어요. HUD 프리셋이 바뀌어도 자동으로 다시 맞춰요 |
| 3 | 전체 화면 | 설정에 **전체 화면 켜기/끄기** 버튼을 넣었어요. 아이폰·아이패드는 지원하지 않는다는 안내와 “홈 화면에 추가” 방법도 함께 보여요 |
| 4 | 자동낚시 | Lv.1부터 열려요. 10레벨 보상에서 자동낚시를 빼고 **희귀 이상 상자 1개와 강화석 20개**를 넣었어요(아래 설명). 잠금 UI와 진행 링은 넣지 않았어요 |
| 5 | 낚싯대 문구 | 추가옵션 슬롯이 0인 낚싯대는 “추가옵션 0슬롯” 문구를 지웠어요. 옛 설명에 남아 있던 “(옵션 3·4슬롯)”과 “랜덤 옵션 1”도 지웠어요. 실제로는 용왕만 1슬롯이에요 |
| 6 | 다른 데크에서 낚시 안 됨 | **재현:** 의자 50개 중 10개에서 실패했어요. AI 이웃이 “주인”으로 잡은 데크라서 막혀 있었어요. **수정:** 의자 배치(W1)에서는 내가 앉은 의자로 낚시 가능 여부를 판단해요. **테스트:** 의자 50개 모두 통과 |
| 7 | XP 알림 | 기본은 PC·모바일 모두 **A2**(낚시 카드 바로 아래 가운데)예요. 설정에서 **A4**로 바꿀 수 있어요: PC는 하단 메뉴·낚시 버튼 위, 모바일은 오른쪽 버튼 묶음 위. 일어나기·낚시 버튼이나 튜토리얼과 겹치지 않게 자동으로 피해요 |
| 8 | 튜토리얼 퀘스트 | 7단계를 넣었어요(아래 4장). 기본은 PC·모바일 모두 **D2**(할아버지 말풍선)예요. PC는 할아버지 그림을 누르면 그림은 그대로 두고 목표만 접혔다 펴져요. 모바일은 그림을 누르면 말풍선이 닫혀요. 설정에서 D4와 위치를 바꿀 수 있어요: PC는 하단 가운데·왼쪽·오른쪽, 모바일은 위·아래, 모바일 D4는 채팅 버튼 아래예요. 이미 Lv.5 이상이거나 30마리 이상 낚은 사람은 자동으로 건너뛰어요 |
| 9 | 칭호 변경 | 아래 6장 참고. **설정 › 프로필 › 칭호**에 선택 메뉴를 새로 넣었어요 |
| 10 | 관리자 특별 칭호 | 관리자 › 테스트에서 줄 수 있어요: 대상 닉네임, 칭호명, 테두리·배경·글자 색, 미리보기, 주기·회수. 받은 사람은 프로필에서 고르면 상단바에 그 색으로 보여요 |
| 11 | UI 편집 모드 1차 | 관리자 › 테스트 › **편집 시작**을 누르면 주요 HUD 11개(상태바·날씨·메뉴·채팅·하단 메뉴·낚시 버튼·튜토리얼·조이스틱 등)를 끌어서 옮길 수 있어요. 위치는 PC와 모바일을 따로 자동 저장하고, 전부 초기화도 돼요 |

**10레벨 보상 바꾼 이유:** 자동낚시는 “계속 쓰는 편의 기능”이었어요. 그래서 그 자리에는 바로 체감되는 성장 보상을 넣었어요. 희귀↑ 상자는 낚싯대·부적이 나올 확률이 있고, 강화석 20개는 첫 강화 몇 번에 쓸 수 있는 양이에요. 기존 10레벨 보상(코인, 고급↑ 상자, 어항 칸 +5)은 그대로예요.

## 2. 시안 (게임에는 넣지 않았어요)
- **12 전설 낚싯대:** L1 천룡 / L2 은하수 / L3 화룡 / L4 심해 고래뼈. 각 안마다 모델 그림, 능력치, 고유 효과, 얻는 법을 넣었고, 등급 색 G1~G3도 있어요. **추천: L1(기본 전설) + L2(신화 상자 한정), 등급 색 G2**
  - 능력치 원칙: 용왕(입질 45%, 대어 +60%, 희귀 +100%)보다 **항목마다 5~20%p만** 높게 잡았어요. 대신 고유 효과로 개성을 줘서 “무조건 더 센 것”이 되지 않게 했어요.
- **13 낚싯대 상세 단순화:** S1 한 줄 요약 / S2 막대그래프 / S3 탭 분리 / S4 카드 뒤집기 / S5 장착 중인 것과 비교. **추천: S1 + S5** (S1은 처음 보는 사람에게, S5는 “바꿀까 말까” 고민할 때 좋아요)
- **18 후원 버튼:**
  - PC: B1 상단 메뉴 첫 칸 / B2 하단 메뉴 6번째 칸 / B3 오른쪽 아래 둥근 칩 / B4 낚시 정보 줄 옆 작은 링크
  - 모바일: M1 ☰ 메뉴 안 / M2 코인 칸 옆 하트 / M3 조이스틱 위 칩 / M4 채팅 버튼 옆
  - **추천: PC B1, 모바일 M1** (게임 화면을 가리지 않고, 찾으려는 사람은 쉽게 찾아요)
- **19 후원 창:** W1 커피 한 잔 / W2 할아버지 편지 / W3 금액 카드 / W4 서버비 목표 막대 / W5 낚시 후 작은 알림. **추천: W1 기본 + W4(목표가 있을 때)**. W5는 “하루 1번, 닫으면 7일간 안 뜸” 조건일 때만 써요.
  - 계좌번호와 QR은 모두 **가짜 예시**예요. 빨간 “예시” 표시가 있어요.
- **16 BGM:** 6곡, 90~110초. 파이썬으로 직접 합성했어요(`tools/bgm-v25.py`). 외부 음원은 쓰지 않아서 **저작권 문제가 없어요.** 시안 페이지에서 바로 들어볼 수 있어요.
  - **솔직한 품질 평가:** 단순한 신스 소리(사인파·플럭·벨에 리버브)예요. 잔잔한 배경음으로는 쓸 만하지만, 멜로디가 무작위로 흘러가서 “곡” 느낌은 약해요. 상용 게임 수준은 아니에요. 출시용으로는 작곡된 CC0 음원(예: OpenGameArt의 CC0 표시 곡, 출처 확인 필수)이나 외주를 추천해요.

## 3. 초반 낚시 속도 (v24 제안 유지)
첫 10마리 입질 시간 절반 + 처음 3마리 쉬운 미니게임 + Lv.5까지 경험치 ×1.5를 함께 쓰는 걸 추천해요. 이번에 자동낚시를 Lv.1에 열었기 때문에 체감 속도가 더 좋아져요.

## 5. 50~100단계 튜토리얼 계획 (17)
**가정:** 수동 낚시로 1분에 약 30 XP를 얻는다고 봤어요(일반어 10~18 XP, 도감 신규·목표 보너스 포함). 레벨 누적 XP는 Lv5 1,446 / Lv10 8,428 / Lv15 22,792 / Lv20 45,742예요.

|---|---|---|---|---|---|

| 4 도감 | 31~42 | 10종·20종, 밤 물고기, 비 오는 날 물고기 | XP 1,500, 상자 3 | Lv.10 | 2시간 30분 |

- **합계:** 80단계, 보상 XP 약 12,300(Lv.20까지 필요한 XP의 약 27%), 코인 약 6,000, 상자 6~8개.
- **지루하지 않게 하는 규칙:**
  - 한 단계는 길어야 15분이에요.
  - 5단계마다 “작은 상자”를 줘요.
  - 장이 끝날 때마다 칭호나 꾸미기 보상을 줘요.
  - 같은 종류의 목표가 3번 연속 나오지 않게 해요.
  - 하루 권장량은 1~2장이에요. 1주일이면 끝나고, 그다음은 업적과 이벤트로 넘어가요.
- 100단계로 늘린다면 10장 “마스터”(전설 1마리, 도감 50% 등)를 넣고 Lv.30까지 이어가는 걸 추천해요.

## 6. 칭호는 어디서 바꿔요? (9)
- **원래는 바꾸는 곳이 없었어요.** 레벨 칭호(Lv5 새내기 낚시꾼 → … → Lv99 낚시의 신)는 **가장 높은 것이 자동으로** 붙었어요.
- 그래서 **설정 › 프로필 › 칭호** 메뉴를 넣었어요.
  - 고를 수 있는 것: 자동(가장 높은 칭호), 이미 딴 레벨 칭호, 관리자에게 받은 특별 칭호.
- **특별 칭호 주의:** 지금은 이 브라우저(localStorage)에만 저장돼요. 그래서 **다른 사람 기기나 다른 사람 화면에는 보이지 않아요.** 진짜로 주려면 서버(계정 DB)가 필요해요.
  - 서버 단계에서 할 일: `titles` 테이블(유저ID, 칭호, 색 3개, 준 사람, 날짜)을 만들고, 이름표를 그릴 때 서버 데이터를 읽게 해요.

## 7. UI 편집 모드 검토 (11)
- **1차 (적용):** 위치 옮기기·저장·초기화. CSS `translate`만 써서 기존 위치 계산과 부딪히지 않아요.
- **2차 (설계만, 품질 기준 미달이라 넣지 않음):** 글자와 이미지 바꾸기.
  - 넣지 않은 이유: 지금 UI 글자는 대부분 코드가 계속 다시 그려요. 그래서 바꾼 글자가 금방 원래대로 돌아가고, 번역이나 업데이트할 때 꼬여요.
  - 설계:
    1. 화면 글자를 `data-t="키"` 방식(문구 사전)으로 바꿔요.
    2. 관리자가 사전 값을 고치면 서버에 저장해요.
    3. 이미지는 “슬롯 이름 → 이미지 주소” 표로 바꿔치기해요.
    4. 미리보기 → 적용 → 되돌리기 기록을 남겨요.
  - 예상 작업: 2~3일.

## 8. 낚싯대 10개 합성 제안 평가 (14)
- **좋은 점:**
  - 규칙이 아주 쉬워요.
  - 남는 낚싯대에 쓸모가 생겨요.
  - 오래 하면 반드시 다음 단계에 닿는다는 목표가 생겨요.
- **문제점:**
  1. 상점에서 사는 낚싯대(카본~벚꽃)까지 되면 **코인만으로 상자 전용 낚싯대를 만들 수 있어요.** 예: 벚꽃 10개(12만 코인) → 황금. 이러면 상자 가치가 떨어져요.
  2. 지금 있는 “2개 합성 → ★+1”과 헷갈려요.
  3. 랜덤 옵션을 어떻게 할지 정해야 해요.
- **추천 규칙:**
  - **상자 전용 낚싯대에만** 적용해요: 황금 ×10 → 별빛, 별빛 ×10 → 용왕, 용왕 ×8 → 전설(L1).
  - 수수료: 5,000 / 20,000 / 80,000 코인. 상점 낚싯대는 그냥 사는 게 더 싸게 유지해요.
  - ★ 합성(2개)은 그대로 두고, 10개 합성은 “단계 올리기” 탭으로 따로 만들어요.
- **랜덤 옵션:**
  - 기본옵션 품질은 재료 중 **가장 좋은 3개의 평균**으로 해요. 그래서 손해를 보지 않아요.
  - 추가옵션은 재료에 있던 옵션 중 **하나를 직접 골라** 물려받아요(수치는 새 등급 범위 안에서 다시 굴림).
  - ★와 강화(+)는 0으로 시작하고, 대신 **강화석 50%를 돌려줘요.**
- **경제 영향:** 상자 전용 낚싯대가 시장에 쌓이지 않고 줄어들어요(10개 → 1개). 그래서 오히려 인플레이션을 막아줘요. 다만 상자에서 낚싯대가 나오는 확률(지금 10%)이 너무 낮으면 10개 모으기가 몇 주가 걸려요. 적용 전에 시뮬레이션이 필요해요.

| 떡밥 | 1 | 100/20개 | 5 | **-30%** | - | 붕어류 ×2 | **너무 셈**: 싸고 빠르고 특기까지 |
| 옥수수 | 3 | 120/20개 | 6 | -10% | - | 잉어 ×1.6 | **떡밥보다 비싸고 약함** → 아무도 안 씀 |
| 민물새우 | 5 | 150/20개 | 7.5 | -15% | +5% | 쏘가리 ×2.5 | 적당 |
| 황금 떡밥 | 12 | 600/10개 | 60 | -50% | +20% | - | 적당(고급 소모품) |
| 스푼 루어 | 18 | 8,000 영구 | - | -10% | +10% | 배스·가물치 ×3 | 적당 |
| 야광 미노우 | 26 | 6,000 영구 | - | -10% | +10% | 밤에만 ×1.5 | **늦게 열리는데 더 싸고 약함** |
| 개구리 루어 | 36 | 12,000 영구 | - | -5% | +15% | 가물치 ×2.5 | 입질이 느려 아쉬움 |

**고칠 점 제안:**
1. 떡밥 입질 -30% → **-20%**.
2. 옥수수: 가격 80, 입질 -15%, 잉어 ×2.2, 대어 +10%. “잉어 전용”으로 개성을 줘요.
3. 야광 미노우: 밤에 메기·뱀장어·송어 **×2.5**, 입질 -15%, 가격 9,000.
4. 개구리 루어: 입질 -10%.
5. 영구 루어 3종에는 “어종 특화”라는 설명 아이콘을 붙여서 언제 쓰는지 알기 쉽게 해요.

## 10. 후원 보상 아이디어와 법적 주의점 (20)
**안 A: 커피 단계형 (추천)**

| 금액 | 보상 |
|---|---|
| 1,000원 | 🎫 낚시 이용권 1 + 감사 이모티콘 |
| 3,300원 | 이용권 3 + 🎁 고급 상자 1 |
| 5,000원 | 이용권 5 + 희귀 상자 1 + 후원 이름표 테두리(30일) |
| 10,000원 | 이용권 12 + 희귀 상자 2 + 후원자 칭호 「호숫가 후원자」 |

- **첫 후원 보너스:** 금액과 상관없이 처음 1번은 보상 ×2와 기념 칭호 「첫 응원」을 줘요.
- **누적 칭호:** 1만 원 「호숫가 친구」 → 5만 원 「등대지기」 → 10만 원 「호수의 수호자」(테두리 색 선택 가능).
- **서버 감사 이벤트:** 이번 달 목표(예: 서버비 10만 원)를 채우면 **모든 유저**에게 주말 “황금 떡밥 데이”(입질 -20%, 2일)를 열어요. 후원하지 않은 사람도 혜택을 받아서 분위기가 좋아져요.

**안 B: 보상 최소형** — 칭호와 이름표 꾸미기만 줘요(게임 능력에 영향 없음). 법적으로 가장 안전해요.

**안 C: 월 정기 응원** — 월 3,300원이면 매일 이용권 1장과 이름표 테두리를 줘요. 구독이라 통신판매업 신고가 필수예요.

**부담 없게 만드는 규칙:**
- 능력치 차이는 작게 해요(상자는 확률 공개).
- 팝업은 하루 1번까지만 띄워요.
- 후원 안내 문구에 “후원은 선택이에요”를 꼭 넣어요.
- 후원하지 않아도 모든 콘텐츠를 즐길 수 있게 해요.

**후원 문구 아이디어 12개:**
1. “오늘 손맛 좋았다면, 개발자에게 커피 한 잔 어때요? ☕”
2. “이 호수의 물고기 밥값은 여러분의 응원으로 마련돼요 🐟”
3. “작은 응원 하나가 새 물고기 한 마리가 돼요.”
4. “서버도 낚시꾼도 쉬지 않게, 살짝 응원해 주세요.”
5. “후원은 선택! 그래도 해주시면 할아버지가 아주 좋아해요 👴”
6. “지렁이 한 통 값(1,000원)이면 충분해요 🪱”
7. “다음 업데이트의 미끼가 되어 주세요.”
8. “혼자 만드는 게임이라, 한 분 한 분이 큰 힘이에요.”
9. “낚시는 공짜, 응원은 마음대로 🙂”
10. “이번 달 서버비 목표까지 조금 남았어요!”
11. “오늘의 월척은… 여러분의 응원 💛”
12. “커피 한 잔 = 개발자 야근 1시간 버티기 ☕”

**법적 주의점 (한국, 쉬운 말):**
1. **보상을 주면 “판매”로 볼 수 있어요.** 돈을 받고 게임 아이템을 주면 사실상 유료 아이템 판매예요. 그래서 아래 의무가 생겨요.
   - 게임 등급분류(유료 아이템이 있으면 필수), 이용약관, 환불 규정.
   - 청약철회 안내(“사용하지 않은 아이템은 7일 안에 환불” 등).
2. **통신판매업 신고:** 인터넷으로 계속 팔면 구청이나 정부24에 신고해야 해요. 1년에 50건 미만이거나 매출이 작으면 면제될 수 있지만, 후원이 늘면 바로 신고하는 게 안전해요.
3. **세금:** 후원금도 **사업 소득**이에요. 사업자등록을 하고, 부가세(1월·7월)와 종합소득세(5월)를 신고해야 해요. 개인 계좌로 받아도 신고 의무는 같아요.
4. **계좌 노출 위험:** 개인 계좌번호를 게임에 그대로 띄우면 다음 위험이 있어요.
   - 사기 신고나 1원 입금 메시지로 괴롭힘을 당할 수 있어요.
   - 계좌가 지급정지될 수 있어요(“보이스피싱 의심”으로 신고되면 계좌가 막힐 수 있음).
   - 실명이 노출돼요.
   - **추천:** 개인 계좌 대신 토스페이먼츠·카카오페이 같은 결제(PG)나 **후원 플랫폼**(투네이션, 트윕, Buy Me a Coffee 등)의 링크와 QR을 써요. 계좌를 쓰더라도 사업자 계좌나 별도 계좌에 예금주명만 보이게 해요.
5. **확률형 상자를 주면 확률 공개가 의무예요.** 2024년 3월부터 게임산업법에 따라 유료(후원 보상 포함)로 주는 확률형 아이템은 **아이템별 확률을 게임 안과 홈페이지에 공개**해야 해요. 어기면 시정명령과 벌칙이 있어요. 지금 상자 등급 확률표가 있으니 이것을 “공개 페이지”로 만들면 돼요.
6. **미성년자:** 미성년자가 부모 동의 없이 결제하면 부모가 취소할 수 있어요. 결제 수단(PG)의 본인 인증을 쓰는 게 안전해요.
7. **기부금이 아니에요:** “기부”라는 말을 쓰면 기부금품법 문제가 생길 수 있어요. **“후원”·“응원”**이라는 말을 쓰고, 보상은 “감사 선물”로 표현해요.

> 법률 자문은 아니에요. 실제로 받기 전에 세무사나 게임 전문 변호사와 30분 상담하는 걸 추천해요(무료 상담: 한국콘텐츠진흥원 콘텐츠공정상생센터).

## 11. 품질 이슈 (솔직하게)
- **특별 칭호·UI 편집 위치·튜토리얼 진행**은 이 브라우저에만 저장돼요. 서버가 생기면 계정으로 옮겨야 해요.
- **UI 편집 2차**(글자·이미지 바꾸기)는 품질 기준에 못 미쳐서 넣지 않았어요(7장).
- **BGM**은 직접 들어 보는 검수는 못 했어요. 음량 측정만 했어요(평균 -14~-18dB, 최대 -1.4dB, 찢어짐 없음). 단순한 신스라 출시용으로는 부족할 수 있어요.
- **신화 컷인 원인**은 코드 분석과 스크린샷 비교로 찾았어요. 한 장면 스크린샷으로는 차이가 크게 보이지 않아서, 실제 기기에서 한 번 확인해 주세요.
- **튜토리얼 5단계 “물고기 팔기”**는 자동 판매로 코인이 들어와도 완료돼요(직접 팔지 않아도 됨).
- **전설 낚싯대 L3**는 불사조로 요청해서 만들었는데 그림이 용 머리로 나왔어요. 그래서 이름을 “화룡”으로 바꿨어요.
