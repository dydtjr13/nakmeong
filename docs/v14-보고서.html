낚멍 v14 보고서

적용

  • 영웅 등급 이상 상자에서는 미끼가 안 나옴 (D.BOX.baitMaxTier=2). 용왕 낚싯대는 신화 상자에서만 나옴.
  • 낚싯대 추가옵션: 등급별 최소~최대 범위 안에서 굴림. 툴팁에 범위 lo~hi% 표시.
  • 보물 탐지·감정 달인 상한 300%. 게임 시간은 그대로.
  • 말풍선:
  • 닉네임(1~3위는 왕관) 위에 고정.
  • 머리 본 대신 캐릭터 위치 기준, 정수 px로 그려서 떨림을 없앰.
  • 휠 줌을 부드럽게 보간하고 overscroll-behavior:none을 넣어 스크롤 때 화면이 흔들리지 않게 함.
  • 1~3위 닉네임 표시는 v10 시안 D (왕관·칭호·오라). 기존 발광 태그를 대체하고, 설정 on/off 스위치는 유지.
  • 창 바깥을 누르면 창이 닫힘. 드래그, 입력, 창 안쪽 클릭으로는 닫히지 않음.
  • 기본값: 낚아 올리는 모션 E, 낚시 버튼 F, 수집 목표 알림 D, 낚음 효과음 C, 상자 효과음 A. 나머지는 설정에서 고를 수 있음.
  • 날씨: 기본은 맑음.
  • 낮 날씨는 4~7분마다 굴림: 계절 날씨 22%, 이슬비 15%, 소나기 8% (여름 15%).
  • 밤 날씨는 밤마다 한 번 굴림: 오로라 2% (겨울 4%), 별똥별 12%, 반딧불 25% (여름 40%, 겨울 0%).
  • 효과: 이슬비 입질 대기 −5%, 소나기 희귀어 +10%, 반딧불 야행성 어종 +10%, 별똥별 10초 행운 +20%, 오로라 상자 드롭 +30%와 서버 공지.
  • 노을은 다른 날씨 위에 덧씌우는 색조. 비나 눈이 올 때는 50% 세기. 밤 특수 날씨는 노을이 끝난 뒤에 시작.
  • 계절 한정 물고기 4종: 벚꽃송어, 무지개은어 (여름 소나기), 단풍쏘가리, 얼음빙어.
  • 크리스마스 맵: 지형 색만 바꾸고 소품은 넣지 않음.
  • 50명 서버 (로컬 시뮬레이션):
  • 데크는 접속 중일 때만 점유.
  • 30m 밖 캐릭터는 간략 모델로 표시.
  • 채널당 50명, 랭킹 공지는 서버 전체.
  • 관리자 모드 (로컬 테스트 패널): 대시보드, 유저, 운영자, 시간·날씨, 맵, 밸런스, 이벤트. 설정 화면이나 ?admin으로 열기.
  • 설정 테스트 항목: 날씨·계절 강제, 맵 테마, 간략화, 채널.
