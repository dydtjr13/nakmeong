피쉬레스트 FISHREST v23 보고서

게임 이름을 피쉬레스트 (FISHREST) 로 바꿨어요. 저장소와 폴더 이름(nakmeong)은 그대로 두었고, '낚멍'은 가제로 남겨요.

1. 게임 적용

# 내용 위치
1 FPS·draw call 표시: 기본 꺼짐, 켜고 끌 수 있음 설정 › 화면 (출시 전 테스트용)
2 PC HUD 로고 제거 왼쪽 위
3 이름 변경: 피쉬레스트 / FISHREST 시작 화면, 탭 제목, 서버 이름, 도감, 환영 메시지
4 이벤트 시작·종료를 날짜 + 시:분:초로 설정. 빠른 버튼(지금 / 10분 뒤 / 1시간 뒤 / 내일 0시, +10분~+7일), 배율 칩, 실시간 요약(잘못된 시간이면 빨간색) 관리자 › 이벤트
5 공지 바의 × 버튼이 박스 밖으로 나가던 문제 수정. 남은 시간은 관리자 화면에서만 보임 상단 공지
6 대시보드 → 유저 관리 → '← 대시보드로 돌아가기' 관리자
7 이동 속도 조절 (프리셋 + 슬라이더) ?admin 주소로 접속 → 관리자 모드 → 🧪 테스트·디버그 탭 (관리자일 때만 설정에도 보임)
8 부적 고정핀: 문구·배경 없이 오른쪽 위 작은 📌 가방 › 부적
9 상자 10개 결과에 툴팁과 NEW 표시. 마우스를 올리면 NEW가 사라짐 상점 › 상자
10 부적 리스트에 마우스만 올려도 옵션 툴팁 가방 › 부적
+ v22 줄바꿈·잘림 개선 적용, 모바일 최대 화면(아래 3번) 전체

3. 모바일 최대 화면: 가능한 것과 한계

  • 안드로이드 (크롬, 삼성 인터넷): 시작 버튼을 누르면 전체 화면으로 바뀌어 주소창이 사라져요. 설정 › 모바일 전체 화면에서 끌 수 있어요.
  • 아이폰 Safari: 웹 페이지 전체 화면이 막혀 있어요. 대신 공유 › 홈 화면에 추가 아이콘으로 열면 주소창 없이 실행돼요 (manifest와 아이콘을 추가했어요).
  • 공통: 노치·홈 바 안전 영역을 처리했고, 실제로 남은 높이를 감지해요.
  • 한계: 어떤 브라우저든 강제로 최대 화면을 만드는 방법은 없어요. 그래서 높이가 줄어도 겹치지 않는 배치(시안 B)를 같이 적용하는 것을 추천해요.

5. 품질 점검: 남은 문제

  • 관리자 데이터(이벤트, 공지, 유저)는 아직 이 브라우저에만 저장돼요. 다른 사람에게 적용하려면 서버가 필요해요.
  • 게시판과 다른 채널은 시안이거나 예시 데이터예요.
  • 시안 A·B·C·E는 게임에 넣지 않았어요. 고르시면 적용할게요.
