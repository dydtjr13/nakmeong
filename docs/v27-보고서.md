## 4. 라이선스 (러버덕)

원본 JDSherbert 러버덕 팩: 상업 사용 가능 · 크레딧 필수 · **수정·재배포 금지**. 그래서 변형 5종은 직접 만든 오리로 만들었고, 원본 오리는 지금처럼 수정 없이 크레딧과 함께 써요. 작가 허락 메일 초안은 따로 드렸어요(허락을 받으면 원본 기반 변형도 가능).
