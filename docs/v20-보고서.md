# 낚멍 v20 보고서

## 적용 내용
- 가방 배지 30% 축소 (20→14px)
- W1~W4 데크: 의자에 앉아야 낚시 가능 (가까이 가면 '앉기' 버튼). 모닥불 벤치 앉기 가능 (넓은 벤치 2명). 봇도 같은 규칙, 빈자리 2개 이상일 때만 벤치 사용
- 모닥불 벤치가 불을 바라보게 회전. 모닥불 개선 (불꽃 스프라이트·숯·불씨·바닥 빛·깜빡임)
- 빗소리 기본값: 부슬비 R1, 비+천둥 T1. 설정(사운드)에서 변경·10초 미리듣기 가능
