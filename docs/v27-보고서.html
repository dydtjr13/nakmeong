# 항목 결과
1 닉네임 이탈 원인: 이름표 위치를 계산할 때 카메라의 이전 프레임 행렬을 썼어요. 카메라를 빨리 돌리면 한 프레임만큼 늦게 따라가서 튀어 보였어요. 수정: 이름표를 그리기 직전에 카메라 행렬을 먼저 갱신해요(cam.updateMatrixWorld()). 측정(t46, 빠른 회전 8번, 148프레임): 전 최대 493px · 평균 134px → 후 최대 0px · 평균 0.01px
2 천룡·화룡 모든 상자에서 각각 1만 개당 1개(상자 등급과 상관없이 따로 굴려요). 200만 개 시뮬: 천룡 187 · 화룡 183 (약 1/1.07만). 다른 등급 영향은 거의 없어요(신화 상자의 낚싯대 몫에서 천룡·화룡 2%만 빠짐: 별빛 234 · 은하 138 · 용왕 81 · 심해 22).
3 러버덕 설정 설정 › 🦆 러버덕: 크기(0.6~2배) · 이동 속도(0~2.5배, 0=멈춤) · 첨벙 소리 켜기/끄기
5 모바일 UI 편집 모바일에서 편집을 켜면 아래 패널이 떠요: 위/아래/알림 그룹 → 창 목록에서 고르기 → 화살표(1·10·30px) · 크기 −/+ · 이 창만 초기화 · 📤내보내기/📥가져오기(코드). “하나씩” 모드면 고른 창만 끌려서 다른 창이 잘못 움직이지 않아요. 고른 창이 아래쪽이면 패널이 위로 올라가서 가리지 않아요.
6 모바일 화질 원인: v26은 화면 밀도(DPR) 2 이상이면 안티에일리어싱을 끄고 해상도를 1.5배로 묶었어요 → 폰에서 계단·흐림. 설정 › 🖼 화질 저/중/고 (기본 중, 바꾸면 새로고침). 측정(390×844 DPR3 가상폰, 소프트웨어 렌더라 상대 비교만): 저 390×844 49.9ms · 중 780×1688 150ms · 고 1170×2532 300ms. 실제 폰은 GPU라 훨씬 빨라요. 느린 폰은 “저”.
7 하단 메뉴 상점 · 어항 · 자동낚시 · 상자 · 가방 (바 넓이·간격·자동낚시 그대로, 62×52 동일). 위 메뉴 줄: ☕후원 · 📖도감 · 게시판 (아이콘만, 38×32 같은 크기·정렬). 모바일은 ☰ 메뉴 안. 겹침 0 (t47).
7-1 후원 기본 = D3 커피잔 아이콘만. 설정 › ☕ 후원 버튼 → “D3 원래 모양”. 누르면 W1 후원 창. 후원 방법(QR·계좌·링크)은 아직 없어서 “준비하고 있어요”로 표시해요 — 알려 주시면 넣을게요.
8 합성 S1 모루형 기본(대상 + 재료 → 결과). 설정 › ⚒ 합성 화면에서 S2(진행 막대) · S3(목록)로 바꿀 수 있어요. ※ S3는 v26 목록형이고, 시안의 “체크해서 고르기” 버전은 아직 안 만들었어요.
