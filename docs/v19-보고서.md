# 낚멍 v19 보고서

## 1. 캐릭터 사라짐 버그 (원인 확인 · 수정 완료)
**원인**: 봇은 일정 시간마다 접속을 끊었다가 다시 들어와요(접속/퇴장 연출). 퇴장할 때 캐릭터를 숨기고(`visible=false`), **다시 들어올 때 보이게 되돌리는 코드가 없었어요.**
- '멀리 있는 캐릭터 간략화'가 **켜져 있으면** 간략화 코드가 매 프레임 `보이기/숨기기`를 다시 정해 줘서 우연히 문제가 가려졌고,
- **꺼져 있으면** 그 코드가 아무것도 안 해서, 한 번 퇴장했던 봇은 다시 들어와도 영원히 안 보였어요. (이름표·말풍선만 남음)
- 덤으로, 간략화를 껐을 때 이미 간략 모형이 있던 캐릭터는 퇴장 상태여도 보이는 반대 문제도 있었어요.

**수정**
- 재접속 시 캐릭터를 다시 보이게 함
- 간략화 OFF일 때도 '접속 중이면 보임 / 퇴장이면 숨김'을 매 프레임 확인
- 캐릭터 메시의 화면 밖 잘림(frustum culling) 끄기 — 스킨 메시의 경계 구가 움직임과 안 맞아 화면 가장자리에서 깜빡이는 일 예방

**재현·회귀 테스트** `t31`: 간략화 OFF로 저장 후 새로 접속 → 봇 9명 전부 퇴장 → 재접속 → 걷기·줌 반복, 데스크톱·모바일.
- 수정 전: 재접속한 9명 중 **9명 안 보임 (FAIL)**
- 수정 후: **0명 (PASS)**

## 7. 에셋 (Nature Hybrid Pack, Nicrom)
- itch.io 페이지의 다운로드는 **윈도우용 데모 실행 파일(.rar)뿐**이고 3D 모델 파일은 없어요.
- 실제 에셋은 **Unity Asset Store 유료 상품**이고, 라이선스는 작가 답변 기준 **Standard Unity Asset Store EULA**예요.
- Unity 전용 셰이더(바람·물)는 웹(three.js)에서 그대로 못 쓰고, 모델(FBX)만 변환해서 쓸 수 있어요.
- 그래서 이번에는 에셋을 받지 못했고, 맵 시안도 만들지 않았어요.
- **받는 방법**: PC에서 Unity Asset Store 로그인 → 구매 → Unity에서 Import → `Assets/NatureHybridPack` 폴더(FBX·텍스처)를 압축해 주시면, 제가 받아서 glb로 변환하고 맵 시안을 만들 수 있어요.
- 사용 전에 EULA에서 Unity 밖(웹 게임) 사용과 재배포 조건을 꼭 확인해야 해요.
- 무료 대안: Kenney, Quaternius 자연 팩(CC0)이 있어요.
