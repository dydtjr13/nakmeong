- 클램프: **의자 착석 중 / 데크 안 / `_fishSpot` 낚시 중** 이면 스킵 + 착석·낚시 좌표 매 프레임 고정

- `botGoal` 경로: tip 쪽으로 진입 → 해당 데크 stool 배정
- `botFix`(이동 OFF): **자기 데크 stool 우선** 착석
