# 낚멍 v18 보고서

## 적용
1. 부적 합산 효과 비교: 교체·해제 시 떨어지는 옵션도 **빨간색 ▼ −수치%** 와 빨간 막대로 표시
2. 부적 교체 대상 자동 선택: 교체 후 합산 효과가 가장 큰(=잃는 게 가장 적은) 슬롯, 같으면 낮은 등급 슬롯
3. 상자 기본 확률 0.5% → **1.8%**
4. 강화 실패 하락 확률: 레벨이 오를수록 높게 (+0~+7은 하락 없음)
5. 호수 물: 시안 5 기본, 설정에서 1·3·4 선택
6. 낮 밝기: 시안 2 기본, 설정에서 1·3·5·기존 선택
7. 어항: 지금 3D 물고기 기본, 설정에서 A·B(그림 물고기) 선택
8. 캐릭터 선택: 기본 5 + 사람 12 + 동물 10 = 27종 (탭·썸네일). `chars-v18.js` 모듈로 분리 — 나중에 진짜 에셋으로 교체 가능
- 보류: 레벨 시스템, 어항 물고기 목록

## 상자 확률 (보물탐지 300% = 확률 ×4, 직접 낚시 시간당 209마리)
| 항목 | 값 |
|---|---|
| 기본 확률 | **1.8%** (300%에서 7.2%) |
| 시간당 상자 | 낚시 드롭 15.0 + 연속 상자 2.1 = **약 17.1개** |
| 100개 | 5.8시간 |
| 500개 | 29.2시간 |
| 1000개 | 58.3시간 |

연속 상자 하루 10개 제한 이후(하루 약 4.8시간 넘게)는 시간당 15.0개 → 100·500·1000개에 6.6·33·67시간. 보물탐지 0%면 시간당 약 3.8+2.1개.

## 강화 표 (성공률 / 실패 시 1단계 하락 확률)
| 단계 | 성공 | 하락 |
|---|---|---|
| +0~+4 | 100~80% | 0% |
| +5 | 70% | 0% |
| +6 | 62% | 0% |
| +7 | 55% | 0% |
| +8 | 48% | 5% |
| +9 | 42% | 10% |
| +10 | 35% | 15% |
| +11 | 30% | 20% |
| +12 | 26% | 25% |
| +13 | 22% | 30% |
| +14 | 18% | 35% |
| +15 | 15% | 40% |
| +16 | 12% | 45% |
| +17 | 10% | 50% |
| +18 | 8% | 55% |
| +19 | 6% | 60% |

이전: +11~14 30%, +16~19 50%, +10·+15는 안전 구간(바닥)이라 낮은 쪽이 상대적으로 더 자주 떨어져 보였음.
