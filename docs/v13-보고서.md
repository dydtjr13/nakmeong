# 낚멍 v13 보고서

## 적용 (게임)
- 2 행운 상자 획득 알림: 화면 하단 중앙 팝업(회전 광선 + 상자 흔들림) + 가방 버튼 숫자 배지(열면 사라짐). 연속 보상 상자는 분홍 팝업.
- 3 조합 패시브: 접은 상태로 교체·잠금·판매해도 접힌 상태와 스크롤 위치 유지.
- 4 어항 크기 확대: sizeF .95~1.8 (v12 .78~1.3), 물고기 크기는 어항 크기에 맞춰 보정.
- 5 자동 낚시 중 화면 클릭·스페이스 입력 무시 (안내 토스트).
- 7 이동 속도 기본 +35%, 설정 > 테스트 설정에서 +0~50% 조절.
- 9 서버 1~3위 닉네임 메달 표시(시안 D 해석: v12 crown 시안 D 미니멀 글로우), 설정에서 끄기 가능.
- 10 데크 배치 A 큰 원형(기본·30데크) / B 지그재그 2열 / C 만형 6마을 / 기존 20데크 — 설정에서 선택 후 새로고침.
- 11 테스트 봇 0~50명 (설정 → 적용 시 새로고침).
- 13 프레임 상한 60/120/144(기본)/제한 없음. 실제 상한은 모니터 주사율.
- 14 설정·상점·가방·도감·사운드 패널에서 버튼 클릭 시 스크롤 위치 유지.
- 15 성공 카드 B(가로 스트립) 위치 약 20% 위로.
- 18 시안 페이지 이미지 전부 클릭 확대(라이트박스, ←/→, 휠 확대).
- 19 상인 옵션 상한 200%.
- 20 합산 효과 순서: 빠른입질·대물·행운·어종전문가·미끼전문가(낚시) → 보물탐지·보물감정·감정의달인·상인(경제).
- 21 첫 시작 사운드: 낮 '아침 새소리 호숫가', 밤 '밤 연못 합창', 볼륨 20%.
- 22 도감 정렬(흔한 순 → 기대가 낮은 순) + 가격 재설정 (game-data-v13.js).
