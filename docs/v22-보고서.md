### 관리자 모드 (`?admin`)
- **대시보드:** 서버 지표만 보여줘요. 동접, 일일 접속자, 평균 접속 시간, 최고 동접, 기기 비율, 채널별 인원(누르면 그 채널 유저 목록).
- **유저 관리:** 서버별 보기, 닉네임 검색, 수량 지정 지급, 채팅 금지(분), 정지(분). 정지가 강퇴를 대신해요.
- **아이템 복구:** 판매·분해·합성 로그와 스냅샷 비교로 복구해요. 판매 금액을 되돌릴지 선택할 수 있어요.
- **운영자:** 검색 → 선택 → 권한 설정 → 등록 순서예요. 권한은 11개이고, 역할 프리셋은 4개(최고관리자·운영자·CS 상담·모니터)예요.
- **시간·날씨:** 간격을 넓히고 옵션을 늘렸어요. 날씨는 지속 시간(분)을 정할 수 있어요.
- **맵:** 간격을 넓혔고, 올려 두면 미리보기가 떠요.
- **덱:** 1자리 20/30, 2자리 20/25/30 옵션을 넣었고, 올려 두면 미리보기가 떠요.
- **밸런스:** 항목마다 ↺(이전 값) 버튼이 있고, 잘못된 값은 표시돼요. 저장 전에 이전 값 → 새 값 확인 창이 떠요.
- **이벤트:** 시작·끝 시간, 서버별 일괄 선물, 수량 직접 입력.
- **서버 공지:** 화면에 띄울 시간(분)을 정할 수 있고, 내역 목록이 남아요.

## 2. 시안 (mockups-v22/index.html)
- **자동 낚시 버튼:** A0~A4. 추천은 **A4 큰 반원**이에요. 버튼 간격을 50px 넘게 벌려서 겹침이 없어요.
- **날씨 vs 낚시 카드:** W0~W4.
  - 원인은 날씨 캔버스가 HUD 위에 그려지는 것이에요.
  - 추천은 **W1(HUD를 날씨 위로)**이에요. z-index 한 줄만 고치면 되고 성능 부담이 없어요.
- **모바일 줄바꿈·잘림:** 문제 6개를 찾았어요(가방·상점·설정·레벨 챕터 탭이 꺾이거나 잘림, 기본 입력창, 단어 중간 끊김).
  - 개선 CSS(`src/wrap-fix.css`)를 적용하기 전과 후를 비교해 뒀어요.
- **게시판:** B1~B5를 만들었어요. 추가 게시판으로 자랑·거래·버그 제보·공략·건의·채널 모집·이벤트를 제안해요.

## 3. 관리자 개선 제안
**대시보드**
- 개선: 지금은 이 브라우저 기준 수치와 예시 채널이에요. 서버 집계 API로 바꿔야 실제 지표가 돼요.
- 추가: 매출·재화 흐름(코인 생성/소모), 신규 가입 대비 이탈률(D1/D7), 오류 로그 건수, 신고 건수.
- 제거: 기기 비율은 자주 보지 않으니 접어 두기로 충분해요.

**전체 점검**
- 모든 조치(정지·지급·복구·밸런스)에 대한 **관리자 작업 로그**가 필요해요. 누가, 언제, 무엇을 했는지 남겨야 해요.
- **2단계 확인:** 큰 수량 지급이나 서버 전체 선물을 보낼 때 수량을 다시 입력하게 해요.
- **권한별 숨김:** 운영자 권한에 없는 탭과 버튼은 아예 숨기면 실수가 줄어요.
- **밸런스 버전 관리:** 지금은 이전 값 1개만 남아요. 이력 목록을 두고 원하는 버전으로 되돌릴 수 있게 해요.
- **예약 기능:** 공지·이벤트를 예약 등록할 수 있게 해요. 지금은 '지금부터'만 가능해요.

## 4. 품질 검토 (알아 두실 점)
- 다른 채널 유저, 로그, 정지·채팅 금지는 **이 브라우저(localStorage)에만** 저장돼요. 실제 운영하려면 서버가 필요해요.
- 설정의 '테스트' 항목(날씨 강제 등)이 일반 유저에게도 보여요. 다음에 `?admin`으로 옮기는 걸 권해요.
- 덱 미리보기는 위에서 본 렌더 이미지라 실제 화면과 각도가 달라요.
- 게시판은 서버(DB·로그인·신고)가 필요해서 시안만 만들었어요.
