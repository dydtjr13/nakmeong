# 낚멍 v11 보고서 (2026-11-03)

## 게임 반영
1. 도감 물고기 클릭 → 어종별 최대 크기 랭킹 (내 서버/전체 서버 탭, 상위 10, 내 기록 하단 고정, "3위까지 n cm")
2. 어항 정렬: 최근순 / 가격 높은·낮은순 / 등급 높은·낮은순
3. 선물 상자: 낚시 성공 100회마다 1개, 하루 최대 10개 (HUD에 "오늘 n/10")
4. 낚싯대 개성 재설계 (아래 표)
5. 자동 낚시: 깜빡임 제거, 메뉴를 연 상태에서도 계속 낚시, 결과 카드 2.5초, 메뉴 중에는 우하단 미니 알림
6. 채팅 탭: 전체 / 대화 / 시스템
7. 도감에 초월 칸 추가 (분홍/무지개 설정 따름)
8. 수집 목표 → 어항 테마 선택 후 창 닫기 안 되던 버그 수정
9. 상점 강화석 구매 제거
10. 강화 +20까지 확장 + 돌파 보너스 (아래 표)
11. 입질 시간 11~23초(최소 5초, 장비로 단축) + 가짜 입질(찌 흔들림, 이때 당기면 실패)
