## 1. 자동 낚시

**일반 유저**
- 자동 낚시 버튼이 잠겨 있고 **「업데이트 예정」**으로 보여요.
- 켜지지 않아요.

**관리자**
- 관리자 모드 → 유저에서 **닉네임**을 넣고 **이용 시간(분)**을 주면, 그 시간 동안만 자동 낚시를 켤 수 있어요.
- 시간이 끝나면 자동으로 꺼지고 안내가 떠요.

---

## 2. 레벨업 보상 창

- 예전처럼 시간이 지나면 알아서 닫히지 **않아요**.
- **확인** 또는 **닫기**를 눌러야 닫혀요.
- 창이 떠 있는 동안 또 레벨이 오르면, 이전 창은 사라지고 **새 레벨 보상**이 보여요.

---

## 3. 접속 화면 · 저장

**서버**
- 서버 **4곳**, 각 **50명** 정원으로 표시해요.
- (실시간 멀티가 붙기 전에는 실접속 인원 연동이 완전하지 않을 수 있어요. 멀티 작업은 별도로 진행 중.)

**솔로 저장**
- 「솔로 저장 있음」 문구·설정 체크는 **없앴어요**.

**다른 브라우저에서도 이어하기**
1. 설정 열기
2. **저장 코드** 복사
3. 다른 브라우저/기기에서 붙여넣기

이게 지금 가장 쉬운 방법이에요. (계정 클라우드 저장은 나중에.)

---

## 4. 설정 vs 관리자

**일반 설정에 남은 것**
- 프로필(칭호 등)
- 저장 / 저장 코드
- 자동 판매
- 화면·사운드·전체 화면
- 차단

**관리자로 옮긴 것**
- 시안·테스트 스타일 (토스트, 수집 목표, 레벨업 팝업 모양 등)
- 튜토리얼 강제·솔로 저장 같은 개발용 항목
- 각 스타일 옆 **미리보기** 버튼으로 바로 확인 가능

---

## 5. 가방 · 어항

**가방**
- 레벨이 모자란 낚싯대·장비는 쓸 수 없고,
  **「레벨이 낮아서 사용할 수 없어요」**라고 알려 줘요.
- 낚싯대에 **착용 레벨**이 보여요.

**어항**
- 활성 조합 요약 + 물고기 슬롯이 한눈에 들어오게 레이아웃을 정리했어요.
- 자동 판매는 설정에서 그대로 켜고 끌 수 있어요.
