# 낚멍 추가 콘텐츠 기획안 (v18 · 구현 전 검토)

시안: [mockups-v18](https://dydtjr13.github.io/nakmeong/mockups-v18/) 의 "추가 콘텐츠 콘셉트" 섹션. 아직 게임에는 넣지 않았어요.

## 한눈에 보기
| 콘텐츠 | 구현 난이도 | 지금 구조로 가능? | 서버 필요 | 추천 순서 |
|---|---|---|---|---|
| 미끼 캐기 | 낮음 | 가능 (미끼 재고·물가 좌표 있음) | 없음 | 1 |
| 요리 | 중간 | 가능 (버프는 기존 패시브 합산에 시간제 항목 추가) | 없음 | 2 |
| 농사 | 중간 | 가능 (데크 뒤 땅 좌표·시간 흐름 있음) | 없음 | 3 |
| 물고기 모험 | 중간 | 가능 (타이머+보상표, 오프라인 진행) | 없음(조작 방지엔 필요) | 4 |
| 물고기 배틀 | 높음 | 봇 상대는 가능, 실제 유저 대전은 실시간 서버 필요 | **필요** | 5 |

## 1. 물고기 배틀 (3마리 PvP)
- **가능 여부**: 지금은 다른 유저가 봇이라 실제 대전은 서버(WebSocket 방)가 있어야 해요. 그 전엔 "봇·친구 어항 대전"(상대 데이터만 받아 자동 전투)으로 먼저 낼 수 있어요.
- **설계**: 어항 물고기 3마리 선택 → 물고기마다 체력=크기, 공격=등급, 속도=어종. 상성 3종(물·흙·바위). 턴마다 기술 1개(어종별 고유) / 버티기 / 교체. 3판 2선승.
- **이용 연령**: 귀여운 대결·친선전 수준(피·사망 표현 없음, 물고기는 사라지지 않음)이면 전체이용가 유지에 무리가 없어요. **승패에 따라 물고기·코인을 걸거나 빼앗는 방식, 유료 확률 아이템과 직접 연결되는 보상**은 사행성으로 보여 등급 상향 위험이 있으니 피해야 해요. 보상은 칭호·전적·꾸미기로.
- **추가 아이디어**: 주간 리그(브론즈~다이아), 관전·응원 이모지, 어항 조합 패시브가 팀 시너지로 작동, "도감 완성도" 매칭.

## 2. 물고기 모험
- **가능 여부**: 가능. 출발 시각만 저장하면 게임을 꺼도 진행돼요.
- **설계**: 탐험 칸 3개. 장소별 시간(30분/2시간/8시간)·추천 어종. 보내는 동안 그 물고기는 어항 조합에서 빠짐(선택의 고민). 보상: 미끼, 강화석, 소품, 지도 조각(모으면 새 낚시터).
- **추가 아이디어**: 탐험 일지(그림 엽서), 희귀 이벤트("보물 상자를 발견했어요"), 친구 물고기와 같이 보내면 보너스.

## 3. 미끼 캐기 (기본 삽)
- **가능 여부**: 가장 쉬움. 물가 모래밭에 반짝이는 "캐는 자리"를 몇 곳 띄우면 돼요.
- **설계**: 자리에 가서 삽 버튼 → 타이밍 게이지(초록 칸에 탭). 성공 시 지렁이 ×3, 대성공 시 떡밥·새우. 자리마다 하루 5번, 비 온 뒤 2배.
- **추가 아이디어**: 삽 강화(금삽 = 희귀 미끼 확률↑), 가끔 동전·조개·지도 조각, 날씨 연동.

## 4. 요리 (버프)
- **가능 여부**: 가능. 버프는 기존 패시브 합산에 "시간 제한" 항목을 더하면 돼요.
- **설계**: 모닥불(이미 맵에 있음)에서 레시피 선택 → 끓이는 시간. 예) 매운탕(붕어+고추+파) 입질 +10% 20분, 꼬치구이 상자 드롭 +5% 15분. 버프는 1개만 유지(겹치지 않음)해서 밸런스 관리.
- **추가 아이디어**: 레시피 도감, 다른 유저에게 나눠주기(파티 버프), 실패 요리(숯덩이) 연출, 계절 한정 메뉴.

## 5. 농사 (요리 연계)
- **가능 여부**: 가능. 데크 뒤 땅에 3×3 밭(칸 확장은 코인 구매) 또는 "농사 화면" 버튼 둘 다 가능. 데크 뒤 밭은 데크 넓히기 안과 공간이 겹치니 함께 정해야 해요.
- **설계**: 씨앗 심기 → 시간 지나면 수확. 물 주기(호수 물)로 성장 +20%, 일반 물고기를 비료로. 수확물은 요리 재료.
- **추가 아이디어**: 이웃 밭 물 주기(교류), 계절 작물, 허수아비 꾸미기, 대풍년 이벤트.

## 공통 주의
- 새 재화를 늘리기보다 **기존 미끼·상자·강화석과 연결**해 경제가 복잡해지지 않게.
- 모두 "안 해도 손해는 적고, 하면 즐거운" 선택 콘텐츠로.
