낚멍 v17 보고서

고친 것 (v16 점검 7건 + 닉네임)

  1. 원거리 간략화 ON이면 30m 밖 유저가 안 보이던 문제 → 순서 버그 수정 (먼 유저 17/17 표시)
  2. 모바일 설정·관리자 옆 탭이 내용을 가리던 문제 → 모바일에선 위쪽 가로 스크롤 탭
  3. 수집 목표 알림 → 목표 이름이 가장 크게, 보상은 작은 칩으로 줄바꿈
  4. 모바일에서 창 뒤로 채팅이 비치던 문제 → 창이 열리면 채팅·말풍선 숨김
  5. 시작 화면 빨간 천막 → 카메라 가까이·시야를 가리는 소품은 반투명 처리
  6. 접속자 수 불일치 → 채널 인원·대시보드 모두 실제 접속 캐릭터 기준
  7. 캐릭터 시안 색 설명 → 실제 렌더 색을 보고 다시 씀 (v17 시안) - 닉네임을 머리 바로 위로 내리고, 말풍선은 그 바로 위로 - 남자 어린이 캐릭터의 경찰 모자 제거 (모자는 밀짚모자 낚시꾼만) - 설정창 닫기(×) 버튼이 안 보이던 것 수정

상자 확률 계산 (보물탐지 300% = 확률 ×4)

시뮬(tools/sim-time.js, 400명) 기준 시간당 포획: 직접 209마리, 자동 164마리(자동은 상자 ×0.8). 연속 낚시 상자: 100마리마다 1개, 하루 10개까지.

목표 직접 낚시 기본 확률 자동 낚시 기본 확률
시간당 10개 0.95% (연속 상자 포함) / 1.20% (미포함) 1.60%
시간당 20개 2.14% / 2.39% 3.51%

현재 기본값 0.5% → 300%면 시간당 약 4.2개 + 연속 상자 2.1개.

상자 수 시간당 10개 시간당 20개
100개 10시간 5시간
500개 50시간 25시간
1000개 100시간 50시간

하루 약 4.8시간 넘게 하면 연속 상자(하루 10개 제한)가 멈춰서 그 뒤로는 7.9개/17.9개 → 100·500·1000개에 각각 12.6·63·126시간 / 5.6·28·56시간.
