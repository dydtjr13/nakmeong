## 1) 튜토리얼 버그 원인

| 증상 | 원인 | 수정 |
|---|---|---|
| 앉아도 미완료 | `goal.seat`가 `nearSpot()`만 검사 → 벤치/일반 좌석이면 실패 | `mySeat()`로 검사 |
| 상점 판매해도 미완료 | 상점/어항 판매 시 `S.earned` 미증가 | 판매 경로에 `S.earned+=` |
| 장비 임무 불가 | 보상이 장비인데 목표가 **장착** → 닭-달걀 | 스텝 입장 시 `grant`로 선지급 → 장착 목표 |
| 보상 안 들어옴 / 중복·누락 | `give` 후 인덱스만 증가, 실패 시 침묵 · 재진입 시 재지급 위험 | `P.paid[id]` / `P.granted[id]`로 1회 보장, `complete()`에서 지급→저장→다음 |
| 고레벨 즉시 스킵 | `lv>=5` 또는 `caught>=30`이면 전체 스킵 | `lv>=10` **그리고** `caught>=80`으로 완화 |

## 2) 보상 흐름 (검증)

```
목표 달성 → complete(st)
  → give(st.rw)  (paid[id]로 1회)
  → toast 완료+보상
  → P.i++ / baseline 리셋
  → 다음 스텝 grant(있으면)
  → render
```

테스트 t80:
- hello 완료 → 코인 **+30**, `paid.hello=1`, i=1
- wearHat: grant로 모자 지급 → 장착 → 완료 보상 **+80**, 모자 유지
- sell 완료 → 보상 **+120**
- STEPS.length = **50**

### 이번 최적화

1. **save dirty-check**: 직렬화 결과가 이전과 같으면 localStorage 쓰기 생략. `beforeunload`/`visibilitychange`는 `save(1)` 강제.
2. **튜토리얼 MutationObserver 제거**: body 전체 class 감시 → `tick` 내 모달 `show` 폴링으로 대체 (UI 열기 감지 유지, 리플로우 비용↓).
3. **HUD 코인 DOM**: 값이 바뀔 때만 `textContent` 갱신.
