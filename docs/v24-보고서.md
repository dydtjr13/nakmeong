# 피쉬레스트 v24 보고서

## 1. 적용한 것
- 토스트 유지시간: 관리자 🧪 테스트에서 배수(×0.6~3) 또는 고정(2/3/5/8초)
- 전설·신화·초월 컷인: 클릭하면 닫힘(다른 창이 열려 있어도)
- 레벨 테스트: ±1/±10, 1/10/99 바로가기, 직접 입력, 보상 지급 여부
- 랭킹 1~3위 이름표에 현재 레벨 표시
- 만렙(Lv99) 이동속도 +100%
- 모바일 메뉴가 날씨 카드에 가려지던 문제 수정
- 모바일 자동낚시 A5, 짧은 화면 X1, 가방 C1(수량 잘림 수정, 1개/10개 열기 한 줄)
- PC 게시판 P4 기본, 설정에서 P1~P5 바꿔보기(데모 게시판)
- 모바일 이벤트: 시작 E2, 진행 중 E3 / 나머지는 설정에서 변경
- AI 봇 관리자 설정: 채팅 ON/OFF, 행동 ON/OFF(OFF면 빈 의자에 앉아 자동낚시)
- 캐릭터 17종: 남성 낚시꾼(노인어부 피부)·여성 낚시꾼 기본, 생선요리사15, 노인어부20, 스노클다이버25, 선글라스30, 여우35, 밀짚모자40, 고양이40, 펭귄45, 너구리50, 수달55, 곰60, 물범65, 개구리70, 토끼80, 오리90. 옛 저장 자동 변환, 레벨업 보상표도 맞춤.

## 2. 시안(미적용) — [시안 모음](../mockups-v24/)
- A. XP 토스트 위치 A0~A5 (추천 A1 레벨바 옆)
- B. Lv10 전 자동낚시 잠금 B1~B4 (추천 B2)
- C. PC 이벤트 레드 계열 R1~R3 + E2/E4 비교, 겹침 지도. 지금 기본은 R1(임시). R계열 시작 알림이 공지 바와 조금 겹쳐서, 확정하면 공지 바 아래로 옮길게요.
- D. 튜토리얼 D1~D4 (추천 PC D1 + 모바일 D4)

## 3. 초반 낚시가 느린 문제 아이디어
1. **첫 10마리 입질 시간 절반** (가장 추천, 쉽고 효과 큼)
2. 처음 3마리는 미니게임 쉬움 모드(바 넓게)
3. 튜토리얼 보상으로 “새내기 낚싯대”(입질 −20%, Lv10까지)
4. Lv5까지 경험치 ×1.5
5. 흔한 물고기는 미니게임 건너뛰기 버튼
- 추천 조합: 1 + 2 + 4 → 첫 5분 안에 Lv3~4.

## 4. 튜토리얼 기획 (초등학생도 OK)
- 안내: 노인 어부 할아버지. 한 번에 한 가지만, 짧은 말.
1. 낚시 자리로 걸어가기 → 50코인
2. 첫 물고기 낚기 → 지렁이 10
3. 물고기 3마리 → 30XP
4. 상점에서 1마리 팔기 → 100코인
5. 떡밥으로 바꾸기 → 떡밥 5
6. 도감 3종 → 상자 1
7. Lv5 → 칭호 “새내기 낚시꾼” + 부적
- 끝나면 “Lv10에 자동낚시가 열려요” 안내. 언제든 건너뛰기 가능.

## 5. AI 봇으로 사람이 많아 보이게 하면 문제일까?
- **봇이 있는 것 자체는 괜찮아요.** 게임 NPC는 흔해요. 이번 봇은 규칙으로 움직여서 AI기본법(2026.1 시행)의 생성형 AI 표시 대상과도 거리가 있어요.
- **문제가 되는 것:** “동시접속 1,000명”처럼 봇을 진짜 사람 수로 세거나, 봇이 결제를 부추기면 속이는 광고(표시광고법·전자상거래법) 문제가 될 수 있어요. 2025년 데이팅앱이 가짜 계정으로 과징금을 받은 사례가 있어요. 스팀·앱스토어도 숫자 조작은 금지예요.
- **안전하게 하는 법:** ① 이름 옆에 “AI 이웃” 표시 ② 접속자 수는 진짜 사람만 ③ 약관·첫 화면에 “AI 이웃이 함께해요” 안내 ④ 봇은 결제·뽑기 권유 금지 ⑤ 사람이 늘면 봇 줄이기.
- 그래서 관리자 설정(채팅/행동)은 넣었고, “AI” 표시는 다음 버전에 넣는 걸 추천해요.

## 6. 출시 전에 할 일 (순서대로)
1. **사업자등록** — 홈택스에서 신청(무료). 업종: 게임 소프트웨어 개발·공급, 광고, 전자상거래. 서울·수도권은 간이과세가 안 될 수 있어요.
2. **게임제작업·배급업 등록** — 구청/정부24. 1년마다 등록면허세 약 4만원.
3. **통신판매업 신고** — 유료 아이템·구독을 팔 때(1년 50건 미만이면 면제).
4. **게임 등급 받기** — 광고·후원·유료 아이템이 있으면 꼭. 웹게임은 게임물관리위원회(GCRB), 개인은 수수료 50% 할인. 스팀 판매도 한국용 등급이 필요해요.
5. **개인정보처리방침·이용약관** 페이지 만들기(광고 쓰면 필수).
6. **확률 공개** — 상자·뽑기 확률을 게임 안과 홈페이지에 표시.
7. **결제** — PG(예: 토스페이먼츠) 가입. **광고** — 애드센스 등.
8. **도메인·호스팅·문의 메일** 준비.
9. **저작권·상표** — 에셋 라이선스(Kenney CC0 등) 정리, “FISHREST” 상표 검색(KIPRIS).
10. **세금** — 부가세 1월·7월, 종합소득세 5월.
11. **스팀(선택)** — 등록비 $100, 세금정보 입력, 출시까지 보통 5~7주.
