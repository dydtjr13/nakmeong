- **🐾 탈것에 펫 태우기 · 📍 다시 들어오면 있던 자리에서 시작**: 기본으로 켜져요.
  - 서버에 예전 키(`petRide`·`resumePos`)가 `off` 로 남아 있어서 꺼져 있었어요. 새 키 `petRide2`·`resumePos2`(기본 켜짐)를 읽고, 예전 키는 지우지 않고 그대로 둬요.
- **🤖 로봇 캐릭터**: 🎫 이용권을 쓴 사람만 골라요. 서버의 `mythChar = on` 은 이제 일반 유저에게 영향이 없어요.

  - 이미 로봇을 골라 쓰던 유저를 강제로 바꾸지는 않아요 (다음에 캐릭터를 바꿀 때부터 이용권이 필요해요).
- **데크 모양 기본값 = W1 (전체 넓게)**: 지금 서버에 적용된 모양이 기본이 돼서, 처음 들어오는 유저가 데크 모양을 맞추려고 한 번 더 새로 고침되던 일이 없어져요.

## 관리자 모드 (관리자 · 운영자만 보여요)
- 왼쪽 메뉴를 **7묶음**으로 나눴어요: 🏠 홈 / 📢 운영 / 👥 유저·안전 / 💰 상점·밸런스 / 🗺️ 맵·환경 / 🎨 기능·화면 / 🔧 개발자·실험실(기본 접힘).
  - 원래 탭(대시보드 · 유저 · 신고 · 복구 · 운영자 · 시간 · 맵 · 오리 · 밸런스 · 이벤트 · 공지 · 비속어 · 화면·시안 · 테스트 기능 · 칭호 · 테스트·디버그)의 내용과 버튼은 그대로이고, 하위 메뉴가 필요한 부분만 골라 보여 줘요.
  - 예: 「🧪 테스트 기능」 안에 섞여 있던 아이템 가격 · 행운 상자 가격 · 장비 가격은 💰 상점 가격으로, 기차 요금 · 펫/탈것/미션 설정 · 경험치는 💰 묶음으로, 눈 스타일 · 배경음악 · AI 이웃은 🗺️ 맵·환경으로 옮겼어요.
  - 「테스트·디버그」의 이동 속도는 💰 이동 속도로, 인게임 적용 · 알림 유지 시간 · 이벤트 알림 스타일은 🎨 알림으로 옮겼어요. 테스트·디버그 안의 「특별 칭호 주기」(👥 특별 칭호와 같은 기능)는 한 곳에만 보여요.
- 맨 위 **🔍 설정 찾기**: 이름을 치면 어느 묶음에 있는지 보여 주고, 누르면 그 자리로 바로 가요 (테스트 기능 줄도 찾아요).
- 하위 메뉴 이름 옆에 **🌐 바꾸면 모든 유저에게 / 👤 내 화면에만** 표시.
- 칸 값을 바꾸면 **노란색**으로 표시되고, 아래에 **「✏️ 바뀐 칸 N개 · 되돌리기 · ✅ (그 칸의 원래 적용 버튼)」 바**가 떠요. 바의 적용 버튼은 원래 있던 적용 버튼을 그대로 눌러요.
- 운영자 권한은 원래 탭 기준 그대로예요 (권한 없는 탭의 하위 메뉴는 안 보여요).

## 표시 오류 고침 (실제 값은 그대로)
- 기본값이 이미 켜진 기능(예: 달 둘러보기 별자리 소개 B, 달 헬멧 B, 그릴 자리)과 프로필 보기 · 데크 옵션처럼 켜져 있는데 「끄기」로 보이던 줄을 실제 값대로 「모두에게」로 보여요.
- 끄는 값이 없는 모양 고르기 기능(예: 운하 모양, 달 낚시 시점, 폰 가방 화면)은 「끄기」 대신 「기본값」이라고 보여요.
- 고르기 칸에 기본값도 들어가서, 지금 쓰는 값이 그대로 보여요 (예전에는 기본값이 빠져서 다른 값이 보였어요).
- 테스트 기능 자동 분류를 이름 글자로 추측하지 않고 키마다 직접 정했어요 (예: 하늘 택시 → 탈것·펫, 소원 연등 → 맵·날씨).
- 오래 모두에게 켜 둔 켜기/끄기 기능 42개는 「정식 기능」 목록으로 옮겨 표를 짧게 했어요 (화면 목록만 바뀌고 서버 값은 그대로, 「테스트로」 되돌리기 가능).
- 화면·시안 탭의 예전 선택지(`v21 기존` 같은 옛 모양)는 지금 고른 값이 아니면 숨겨요. 맵 탭의 「기존 20데크」도 지금 고른 값이 아니면 숨겨요.
- 「만들기」 버튼 자리 계산 콘솔 오류 수정.
