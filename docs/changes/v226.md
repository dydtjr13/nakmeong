## 사용자 입장에서 달라진 것

- 의자에 앉아 낚시할 때, 고급 낚싯대의 발밑 오로라가 의자 높이에 떠서 옆의 펫을 가리던 문제를 고쳤어요.
- 오로라는 데크(호숫가·달)나 땅(캠프 벤치), 운하 부두 바닥에 붙어요. 바닥에 파묻히거나 깜빡이지 않게, 바닥보다 아주 조금만 위에 있어요.
- 펫은 v225 이전처럼 다시 의자 옆에 서요. 자리를 옮기지 않아요.
- 서 있을 때의 오로라·펫 동작은 그대로예요. 기차나 탈것에 탔을 때도 그대로예요.

## 코드

- `game-v2.js`
  - v225에서 넣었던 앉으면 펫 자리를 데크로 옮기는 처리를 걷어 내, 따라오기·펫 낚시 자리를 예전과 같게 했어요.
  - `rodFloorY` / `rodChairOf` / `rodFootY`: 의자에 앉은 캐릭터(나·다른 유저·봇)의 발밑 오로라 높이를 그 맵의 바닥으로 계산해요. `NK_RODFX.ctx({footY})`로 넘겨요.
- `rod-3d.js`
  - 발밑 오라·고리·기둥이 `CTX.footY`가 있으면 그 높이를 쓰고, 없으면 예전처럼 캐릭터 발 + 0.03을 써요. 용왕·심연·천상·불·마스터 모두 같은 배치예요.
