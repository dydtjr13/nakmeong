## 무엇이 바뀌었나 (일반 유저 기준)
- Lv10부터 호숫가에 **🏡 하우징 섬** 버튼이 생겨요. 누르면 무료 배를 타고 섬으로 가요. (배가 없어도 갈 수 있어요)
- 섬에는 빈 집터 50곳이 있어요. 마음에 드는 집터 앞에서 **농사 땅 사기 (2,500골드, 4칸)** 를 누르면 그 집터가 내 것이 돼요. 집은 아직 없어도 돼요.
- 텃밭 칸의 ＋를 누르면 씨앗 창이 열리고, 작물을 골라 심어요. 한 번 심으면 **연속 심기** 상태가 되어 빈 칸만 눌러도 같은 씨앗이 심겨요.
- 작물은 **실제 시간**으로 자라요. 게임을 꺼 두어도 자라고, 시들지 않아요. 칸 위에 남은 시간과 진행 막대가 보이고, 다 자라면 "수확!"이 떠요.
- 다 자란 칸을 누르면 하나씩, 아래 **모두 수확** 버튼으로 한꺼번에 거둬요. 수확하면 작물 가방에 쌓이고 경험치를 받아요.
- **작물 가방**에서 작물을 팔 수 있어요 (딸기는 팔 수 없어요). 작물은 나중에 요리 재료로 쓸 예정이에요.
- 텃밭 가까이에서 멈추면 카메라가 텃밭이 한눈에 보이게 살짝 옮겨 가요. 움직이면 원래대로 돌아와요.
- **⛵ 호숫가로** 버튼으로 원래 있던 호숫가(같은 서버)로 돌아가요.
- 텃밭은 레벨에 맞춰 넓힐 수 있어요: 4칸 → 6칸(Lv14, 6,500) → 9칸(Lv20, 22,000) → 16칸(Lv37, 120,000) → 25칸(Lv52, 300,000).
- 상자를 열 때 Lv35 이상 + 농사 땅이 있으면 낮은 확률(2.5%)로 딸기 씨앗이 나와요.

## 영상 시안에서 남았던 문제 해결
- 수확 말풍선이 잎을 가림 → 칸 이름표를 작물 높이 위에 띄움
- PC 씨앗 카드 시간이 두 줄로 넘어감 → 카드 안 그림 크기 고정, 줄바꿈 0개 확인
- 모바일 첫 장면 집 잘림 → 이번 1차에는 집이 없어 해당 없음(빈 집터만), 모바일 첫 장면 잘림 없음 확인

  호숫가 버튼 → 배 → 섬 도착 → 17번 집터 땅 사기 → 파 4칸 심기(연속 심기) → 성장(시간 당김) → 수확! → 1칸 수확 → 모두 수확(파 8개, XP +20) → 가방 → 호숫가 복귀(텃밭 저장 유지)
