## 사용자 입장에서 달라진 것

- 산타 썰매가 네모난 블록 모델에서 곡선 모델로 바뀌었어요. 이미 가진 썰매도 새 모습으로 보여요. 속도, 얻는 방법, 가격, 탑승 위치는 그대로예요.
- 썰매: 앞이 말려 올라간 황금 곡선 날과 S자 지지대, 진홍 광택 S자 옆판과 금 테두리, 금 별·소용돌이·눈꽃 장식
- 좌석: 벨벳 쿠션, 하얀 털 테두리, 휘어진 등받이와 금 단추
- 뒤 짐칸: 선물 자루와 지팡이 사탕, 리본 매듭 선물 상자, 원통 선물
- 앞: 빛나는 랜턴, 호랑가시 리스, 금 방울
- 산타는 둥근 모습으로 오른쪽에 앉아요(낚싯대 길을 비워요). 순록 3마리도 둥근 몸과 가지 뿔로 바뀌었고, 루돌프 코가 빛나요.
- 상점과 가방의 썰매 그림(`img/veh/santa.png`)도 새 모델로 다시 그렸어요.

## 바뀐 코드

- `sleigh-v236.js` (새 파일): `SLEIGH_V2(THREE,{lite})`. BoxGeometry 없이 Tube·Extrude(베벨)·Lathe·Sphere로만 만들었어요. 지금 썰매와 약속이 같아요(앞 +z, 바닥 0, ×1.7, `seat=[0,.92,-.45]`, `legs/heads/pose='sit'`). 그래서 다리·머리 흔들기, 펫 자리(PRSLOT), slimGroup은 그대로예요.
- `game-v2.js`
  - `VEHB.V.santa(lite)`: `SLEIGH_V2`가 있으면 새 모델을 쓰고, 없거나 오류가 나면 예전 모델로 돌아가요.
  - `vehMesh(x, lite)`: 두 번째 인자를 받아 모델에 넘겨요. 다른 유저 탈것(RHOOK)은 `vehMesh(k,1)`로 불러요. lite를 지원하는 모델은 지금 산타 썰매 하나예요. 다른 탈것은 인자를 무시해서 그대로예요.
- `nakmeong.html`: `turtle-c3-v158.js` 뒤에 `sleigh-v236.js` 추가
