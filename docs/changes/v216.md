## 무엇이 바뀌었나
- 예전에는 보상이 `골드 50,000 · 강화석 20 · 상자 3개 · …` 한 문단으로만 떴어요. 아이콘이 없고, 상자 등급도 안 적혀 무엇을 얼마나 받았는지 한눈에 안 읽혔어요.
- 이제 가운데 창에 **아이템마다 카드**(아이콘 + 이름 + 수량)가 그리드로 나와요. 보낸 말(사유)은 위쪽 상자, 아래 버튼은 「모두 받기」예요. (지급 자체는 예전과 같이 창이 뜰 때 이미 들어가고, 버튼은 창을 닫아요.)
- 표시하는 종류: 골드, 강화석, 행운 상자(**등급 이름** · 전설/신화 등), 경험치, 크기 변화 이용권(일반·1시간), 미끼, 부적(등급), 낚싯대(등급·별), 장비, 탈것(색 이름), 펫, 캐릭터, 칭호, 물고기(있으면 이름·등급·크기). 알 수 없는 종류는 선물 아이콘 + 이름 + 수량으로 폴백해요.
- 운영자가 준 특별 칭호가 따로 올 때도 같은 카드 창으로 알려요.
- 아이템이 많아 한 화면에 안 들어가면 카드 목록만 밀어서 보고, 「모두 받기」 버튼은 아래에 그대로 보여요.
