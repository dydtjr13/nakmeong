# v242 — 🛒 상점 새 모양 (B안: 왼쪽 목록 · 카드 · 큰 미리보기)

- 날짜: 2026-11-27 (Asia/Seoul)
- 사용자 승인: 「상점은 추천해준 B안으로 진행해 줘」 (시안: `/workspace/shop-redesign-mock/`)

## 바뀐 점
- **PC (폭 900px 이상)**: 왼쪽에 카테고리 목록, 가운데에 4열 카드, 오른쪽에 큰 미리보기가 있어요.
  - 미리보기에서 색을 고르고, 지금 쓰는 낚싯대와 비교(빠른입질·대어·희귀어종)하고, 사고 나면 남는 골드를 보고, 바로 사요.
- **휴대폰**: 위쪽에 5×2 카테고리 칸, 2열 카드, 카드를 누르면 아래에서 상세 창이 올라와요.
- **모든 탭이 같은 카드 모양**: 낚싯대 · 미끼 · 탈것 · 펫 · 데크 꾸미기 · 어항 · 장비.
- 맨 위 **⭐ 추천**: 탭마다 지금 살 수 있는 다음 물건을 모아 보여 줘요.
- **찾기**(이름·효과·색 이름), **살 수 있는 것만 / 보유 중** 거르기, **정렬**(기본순 · 싼 순 · 비싼 순), **작은 칩**(예: 탈것 하늘 / 동물 / 땅·물, 장비 모자 / 옷 / 신발 / 장갑).
- 잠긴 물건은 `🔒 Lv.N` 으로 보여요. 상자에서만 나오는 물건은 `🎁 상자에서` 로 보여요.
- **💰 물고기 팔기**는 사는 카테고리와 따로 아래에 있고, 화면은 예전 그대로예요. 🎁 행운 상자 화면도 예전 그대로예요.
- 탈것 22개(싼타 썰매 v2 · 네온 UFO · 바다거북 4색 · 오픈 전투기 3색 · 버블 전투기 3색 포함)가 모두 보이고, 사기 · 타기 · 팔기가 돼요.
- 갖고 있는 탈것 팔기 버튼은 미리보기 아래 넓은 버튼(「💰 판매하기 · 🪙 N 받아요 (산 값의 30%)」)이라 금액이 넘치지 않아요.
- 가격 · 확률 · 되팔기 30% · 확인 창은 예전과 똑같아요.

## 기술 메모
- 새 파일 `shop-b-v242.js` · `shop-b-v242.css` (모든 규칙은 `#shop .nkb` 안쪽).
- `game-v2.js` 에는 다리 한 줄만 추가: `window.__nkShop` (S · shopTab · renderShop · `_renderShop` 감싸기 · openM/closeM · toast · uiOpt).
- 게임 코드가 시작 준비 뒤에 늦게 돌아서, `shop-b-v242.js` 는 다리가 생길 때까지 기다렸다가 `_renderShop` 을 감싸요.
- 기존 상점(`_renderShop` + 데크·펫·탈것·네온 간판 패치)을 탭마다 그대로 그려 숨겨 두고, 그 화면을 읽어 새 카드로 보여 줘요. 새 화면의 사기·쓰기·팔기 버튼은 숨겨 둔 원래 버튼을 눌러요 → 구매 로직은 바뀌지 않아요.
- 끄기: 관리자 설정 `shopB = off` 이면 예전 상점이 나와요. 새 화면에서 오류가 나도 자동으로 예전 상점을 그려요.
- 원래 게임 CSS 의 `.cmp`(격자) 와 겹치지 않게 비교 상자는 `.nkcmp` 이름을 써요.
