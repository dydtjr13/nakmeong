## 사용자 입장에서 달라진 것

- 같은 종류·같은 별을 겹치는 방법은 그대로예요. 결과는 예전처럼 둘 중 높은 등급을 따라가요.
- 가장 흔한 물고기끼리(일반+일반) 합성은 지금처럼 골드가 안 들어요.
- 더 좋은 물고기끼리 합성할수록 골드가 더 들어요. 끌어다 겹칠 때 필요한 골드가 칸 아래에 보여요.
- 골드가 모자라면 「골드가 모자라요 · 🪙 N 필요」라고 알려 주고, 물고기도 횟수도 그대로예요.

## 비용 표

표시와 실제 차감이 `mergeCost()` 한 함수예요. 비용 = (두 재료의 등급 가중치 합) × 100골드.

가중치: 일반 0 · 고급 1 · 희귀 2 · 전설 6 · 신화 20 · 초월 80 · 슈퍼 160

|  | 일반 | 고급 | 희귀 | 전설 | 신화 | 초월 | 슈퍼 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 일반 | 0 | 100 | 200 | 600 | 2,000 | 8,000 | 16,000 |
| 고급 |  | 200 | 300 | 700 | 2,100 | 8,100 | 16,100 |
| 희귀 |  |  | 400 | 800 | 2,200 | 8,200 | 16,200 |
| 전설 |  |  |  | 1,200 | 2,600 | 8,600 | 16,600 |
| 신화 |  |  |  |  | 4,000 | 10,000 | 18,000 |
| 초월 |  |  |  |  |  | 16,000 | 24,000 |
| 슈퍼 |  |  |  |  |  |  | 32,000 |

슈퍼 초월은 종류가 달라 원래 합성에 안 올라와요. 표에는 모든 등급을 적어 두었어요.

예시 세 가지 (잉어 ★1 + ★1 → ★2, 판매가는 가치의 60% 기준, 추가 보너스 없음):

| 조합 | 비용 | 결과 등급 | 재료 판매 합 | 결과 판매 | 비용 전 이득 | 비용 후 순이득 |
|---|---:|---|---:|---:|---:|---:|
| 일반+일반 | 0 | 일반 | 34 | 25 | −9 | −9 (지금과 같음) |
| 일반+신화 | 2,000 | 신화 | 3,288 | 4,907 | +1,619 | −381 |
| 신화+신화 | 4,000 | 신화 | 6,542 | 4,907 | −1,635 | −5,635 |

같은 계산으로 향어·붕어의 일반+신화도 비용 후 순이득이 마이너스예요. 쏘가리 일반+신화는 판매 이득이 커서, 비용 2,000을 빼도 약 +952가 남을 수 있어요.

일반으로 초월의 별을 올리는 구멍은 비용으로 일부만 줄어들어요. 잉어 일반+초월 ★1→★2는 판매 이득이 약 12,318이고 비용은 8,000이라, 순이득이 약 +4,318 남아요. ★1에서 무지개까지 일반만 먹이로 쓰면 초월 비용 합은 72,000골드예요. 초월 한 마리의 희귀함(약 1/15,000)을 골드만으로 막지는 못해요.

골드(`S.coins`)는 상점·낚싯대 합성과 같이 클라이언트 저장이에요. 하루 합성 횟수만 서버가 세요. 칸에 보이는 금액과 차감 금액은 같은 함수라 항상 같아요.
