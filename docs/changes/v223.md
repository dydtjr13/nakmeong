## 사용자 입장에서 달라진 것
- 합성판에서 어떤 종(예: 향어)을 방금 합쳤는데, 판 위에도 보유 물고기에도 그 종을 더 합칠 같은 단계가 없으면, 판 위쪽에 토스트로 「더 합성할 향어가 없어요」가 떠요.
- 다른 종은 그대로 합칠 수 있어요. (예: 향어는 끝났지만 보유에 붕어가 2마리 있으면, 향어 알림만 뜨고 붕어는 계속 합칠 수 있어요.)
- 같은 상태에서는 한 번만 떠요. 물고기를 더 구해 다시 합치다 또 끝나면 다시 알려 줘요.
- 잠근 물고기·모험 나간 물고기·무지개는 원래 합성 목록에 없어서, 이 알림을 셀 때도 넣지 않아요.
- 합칠 게 하나도 없으면, 예전에 1초 뒤 뜨던 「지금은 합성할 물고기가 없어요」 창은 같은 상태에서 한 번 더 뜨지 않아요. (이미 토스트로 알려 줬어요.)

## 코드
- `merge-board-v192.js`
  - 합성이 끝난 뒤(`evDone`, 새 물고기가 판에 그려진 다음) 방금 합친 종을 판+보유에서 같은 단계 2마리가 더 있는지 봐요 (`spCan` / `spGone`).
  - 알림은 기존 합성판 토스트(`.mbtoast`) 톤이에요. 긴 이름도 잘리지 않게 `.mbwrap`으로 줄을 바꿀 수 있어요.
  - 토스트는 합성 연출 루프와 따로 켜지고 꺼져요. (연출 중에 투명도가 0에 고정되어 안 보이던 문제를 막았어요.)
- `merge-board-v192.css`: `.mbtoast.mbwrap`
- 측정: `NK_MB.measure()` 에 토스트 위치·겹침을 넣었어요.
