## 무엇을 바꿨나

- 슈퍼 초월급 컷인 창(상단 축하 공지 띠)이 시간이 지나면 자동으로 닫히지 않아요. 「닫기」 버튼을 눌러야 닫혀요.
- 창 오른쪽에 「축하하기」 아래, 잘 보이는 「닫기」 버튼을 넣었어요. 글자가 적혀 있고, 높이는 44px 이상이라 PC·모바일 모두 누르기 쉬워요.
- 창의 빈 곳을 눌러도 닫히지 않아요. 새 슈퍼 초월 공지가 오면 예전처럼 새 창으로 바뀌어요.
- v221의 「너무 빨리 눌러도 축하 인원이 올라가기」 수정은 그대로 두었어요.

## 왜

- 예전에는 다른 사람 공지는 30초, 서버 공지가 없는 내 공지는 14초 뒤에 자동으로 사라졌어요.
- 사용자가 직접 닫기 전까지는 축하 창을 계속 보고 싶다고 해서, 자동 닫힘을 빼 달라는 요청이었어요.
