# v222 — 👑 슈퍼 초월급 컷인 창은 직접 닫을 때까지 유지

- 날짜: 2026-11-22 (Asia/Seoul)
- 기준: main `6411d89` (v221 축하하기 빠른 클릭) 위에 이어서. 머지 직전 다시 rebase.
- 서버(Worker) 변경: **없음** (클라이언트만)
- 캐시: `super-transcend-v184.js?v222` · `super-transcend-v184.css?v222` · 가이드 `site.js?v222`

## 무엇을 바꿨나

- 슈퍼 초월급 컷인 창(상단 축하 공지 띠)이 시간이 지나면 자동으로 닫히지 않아요. 「닫기」 버튼을 눌러야 닫혀요.
- 창 오른쪽에 「축하하기」 아래, 잘 보이는 「닫기」 버튼을 넣었어요. 글자가 적혀 있고, 높이는 44px 이상이라 PC·모바일 모두 누르기 쉬워요.
- 창의 빈 곳을 눌러도 닫히지 않아요. 새 슈퍼 초월 공지가 오면 예전처럼 새 창으로 바뀌어요.
- v221의 「너무 빨리 눌러도 축하 인원이 올라가기」 수정은 그대로 두었어요.

## 왜

- 예전에는 다른 사람 공지는 30초, 서버 공지가 없는 내 공지는 14초 뒤에 자동으로 사라졌어요.
- 사용자가 직접 닫기 전까지는 축하 창을 계속 보고 싶다고 해서, 자동 닫힘을 빼 달라는 요청이었어요.

## 검증

- 로컬: 실제 `notice()` 로 창을 띄워 PC 1280×720 · 1920×1080, 모바일 360×640 · 390×844 · 412×915 확인.
  - 가운데 오차 0px, 화면 안, 「닫기」와 「축하하기」 겹침 없음, 「새 업데이트」 띠와 겹침 없음.
  - 「닫기」 글자·크기(PC 약 105×44, 모바일 약 70×44) 확인.
  - 창 가운데를 눌러도 닫히지 않음. 「닫기」를 누르면 닫힘.
  - 1280×720 · 390×844 에서 35초 기다려도 창이 그대로 열려 있음 (예전 최대 30초보다 김).
- 라이브 확인은 머지 후 9번 방에서 진행 (실제 유저 방에는 시험 공지 안 보냄).
