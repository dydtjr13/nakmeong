# v228 — 🖥 화면 설정에서 작은 창을 고르면 기존 작은 창이 열려요

- 날짜: 2026-11-22 (Asia/Seoul)
- 기준: main 최고 문서·코드 버전 **v227**(달 맵 데크 25개). 머지 직전 다시 rebase 후 번호 확정.
- 서버(Worker) 변경: **없음** · LAB 키 추가 **없음**
- 캐시: `game-v2.js?v228` (`nakmeong.html`) · 가이드 `site.js?v228`
- 요청: 화면 설정 창에서 「작은 창」을 고르면, v219에서 되돌린 기존 작은 창(PiP)이 그대로 열리게 해 달라는 것이었어요. 전체화면 선택은 그대로입니다.

## 사용자 입장에서 달라진 것

- 오른쪽 위 화면 설정 버튼(메뉴 ≡ 왼쪽)을 눌러 「작은 창」을 고르고 「작은 창 띄우기」를 누르면, 예전과 같은 작은 창(PiP)이 열려요.
- 테스트 기능 「🖼 작은 창 (PiP)」을 따로 켜지 않아도, 이 브라우저가 작은 창을 지원하면 화면 설정에서 바로 쓸 수 있어요.
- 전체화면을 쓰던 중이어도 「전체화면 끄고 작은 창으로」를 누르면 작은 창으로 바로 바뀌어요.
- 작은 창 설정(창 내리면 자동 · 보여 줄 화면 · 입질 때 반짝이기 · PC 새 창)과 작은 창 동작은 v219와 같아요.
- 이 브라우저·기기가 작은 창을 지원하지 않으면, 예전처럼 「작은 창」카드가 잠기고 안내가 나와요.
- 전체화면 선택은 그대로예요. 메뉴 안의 「작은 창」버튼은 테스트 기능을 켠 경우에만 예전처럼 보여요.

## 코드

- `game-v2.js` 작은 창 모듈
  - 브라우저 지원 `can()`과 메뉴 버튼용 `on()`(`pipOn` 켜짐)을 나눴어요. `NK_PIP.ok`는 `can`을 가리켜요(화면 설정이 「작은 창을 쓸 수 있나」를 볼 때 사용).
  - `NK_PIP.open()`(= 기존 진입)은 `can()`이면 엽니다. 문서 작은 창이 실패하면 동영상 작은 창으로 이어져요.
  - 메뉴 「작은 창」버튼과 창을 내릴 때 자동으로 열기는 기존처럼 `on()`(pipOn) 뒤에 둡니다.
- `game-v2.js` 화면 설정 모듈
  - 「작은 창 띄우기」는 기존처럼 `NK_PIP.open()`만 불러요.
  - 전체화면을 먼저 끌 때, 끝나기를 기다리지 않고 같은 클릭에서 바로 `NK_PIP.open()`을 불러요. 기다리면 브라우저가 '방금 누른 동작'을 잊어 작은 창이 안 열릴 수 있어요.
