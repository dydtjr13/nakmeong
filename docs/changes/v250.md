- 버전: v250 (main 최고 v249 + 1)
- 사용자 요청: 진주 아이콘은 C안으로 진행. 게임과 가이드에서 진주(캐시 재화)를 보여주는 모든 곳(상단 재화, 상점 가격, 구매 확인 창, 캐시 상점, 보상 안내, 관리자)에 C안을 쓰고, 16~20px에서도 또렷하게 보이도록 크기별 이미지를 만들 것.

## 일반 유저에게 바뀐 점
- 상단 재화 칸에 골드 옆으로 **진주**가 보여요. 아이콘은 오팔빛 C안이에요.
- 상점에 **진주 상점** 칸이 생겼어요. 충전 묶음을 볼 수 있고, 가격 옆에도 같은 진주 아이콘이 붙어요.
- 충전하기를 누르면 확인 창이 떠요. **결제는 아직 준비 중**이라 지금은 바로 충전되지 않아요.
- 골드 탈 것 가격은 바꾸지 않았어요. 진주로 사는 탈 것은 아직 넣지 않았어요.
- 운영자가 보상·일괄 지급·예약 보상으로 진주를 보내면, 안내 창에도 C안 아이콘이 나와요.
