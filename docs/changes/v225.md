## 사용자 입장에서 달라진 것

- 의자에 앉아 낚시할 때, 고급 낚싯대의 발밑 오라·광륜에 펫이 가려지던 문제를 고쳤어요.
- 펫은 의자·캐릭터와 겹치지 않게, 물 반대쪽 데크(또는 캠프 의자 옆 땅) 바닥에 서요. 물에도 빠지지 않아요.
- 다른 사람이 보는 화면에서도 같은 자리에 보여요 (같은 자리 잡기).
- 일어서서 걸을 때는 예전처럼 옆을 따라다녀요. 탈것에 같이 타는 동작은 그대로예요.

## 코드

- `game-v2.js`
  - `petFloorY` / `petGY`: 발 높이는 데크·땅만 써요. 운하에서 물 위 자리일 때 의자 높이로 올리지 않아요.
  - `petOwnerSeat` / `petSitTarget` / `petSitCached`: 앉은 주인의 펫은 물 반대쪽·살짝 옆, 약 2.1m 떨어진 바닥 자리를 찾아요. 데크 안·걷기 가능·다른 의자·캐릭터와 0.7m 이상 떨어짐을 확인해요. 0.5초마다 다시 계산해요.
  - `petFollow`와 펫 낚시 자리(나·다른 유저)가 이 자리를 같이 써요. 앉아서 펫이 낚싯대를 들면, 찌는 의자 앞에서 물 쪽으로 나가요.
