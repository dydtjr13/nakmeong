# v244 — 🛒 상점 이미지 잘림 수정 · 구매 확인 창 · 코지 확인 UI

- 날짜: 2026-11-27 (Asia/Seoul)
- 사용자 요청: 「상점에 이미지 잘린 것들 찾아서 수정해 줘 · 구매 버튼 클릭 시 확인 창 안 뜨고 바로 구매되는 것들 찾아서 확인 창 뜨도록 해줘 · 확인 창 톤앤매너 맞지 않고 일반 웹사이트 확인 창처럼 뜨는 것들 찾아서 UI 수정 후 적용해 줘」
- 백업: `/workspace/nakmeong-backups/shop-confirm-pre-20261127-1724.bundle`

## 일반 유저에게 바뀐 점
- **상점 구매 확인 창**: 낚싯대·미끼·탈것·펫·어항·의상·데크 꾸미기(판 색·간판·소품)·행운 상자를 살 때, 바로 골드가 빠지지 않고 「🛒 구매할까요?」 창에서 이름·가격·사고 나면 남는 골드를 보고 확인/취소할 수 있어요.
- **확인 창 디자인**: 브라우저 기본 확인 창 대신, 피쉬코지 크림색 둥근 카드·주황 확인 버튼으로 바뀌었어요. 바깥을 누르거나 Esc, 취소를 누르면 닫히고 구매되지 않아요.
- **상점 이미지**: 카드·큰 미리보기·색 고르기 칸의 물건 그림이 잘리거나 삐져나오지 않게 안에 맞춰 보여 줘요. 휴대폰 행운 상자 아래 확률 칸이 창 바닥에 잘리지 않도록 여백을 넣었어요.

## 관리자 · 기타
- 관리자 「모든 유저에게 적용할까요?」 같은 확인도 같은 코지 창으로 떠요 (브라우저 기본 창이 아니에요).
- 게시판 글/댓글 삭제, 탈것 만들기에서 빼기, 화면 배치 코드 복사·붙여넣기도 같은 코지 창을 써요.

## 기술 메모
- `confirmBox` / `alertBox` / `promptBox` / `_cfAsk` / `buyAsk` 를 추가·개편했어요. ESC · 바깥 클릭 · 취소 · 확인, 가운데 정렬 0px.
- 게임 안의 `confirm()` / `alert()` / `prompt()` 호출을 코지 창으로 바꿨어요. (`window.confirm` 은 `#confirm` 요소가 없을 때만 최후 수단으로 남겨 뒀어요.)
- `shop-b-v242.css` / `shop-b-v242.js`: 썸네일·미리보기 `object-fit: contain`, 복제 그림의 고정 크기 제거, 그리드·상자 탭 아래 여백.
