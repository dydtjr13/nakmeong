## 문제
- 판매 모드 가운데 버튼이 고른 물고기를 모두 세서(잠긴 물고기 포함) "3마리 팔기"로 보이고, 확인 창은 "2마리 · 잠긴 1마리는 팔지 않아요"로 숫자가 달랐어요 (v212 보고에서 발견, 예전부터 있던 것).
- 잠긴 물고기만 골라도 팔기 버튼이 켜져 있었어요 (누르면 "잠긴 물고기는 팔 수 없어요" 알림).

## 수정 (`merge-board-v192.js` `drawBB()`·`draw()`, `merge-board-v192.css`)
- 팔기 버튼 숫자 = **잠기지 않은 물고기 수**, 골드 미리보기 = 그 물고기들의 `sellP` 합 (예전에도 골드는 잠긴 물고기를 뺐어요) → 확인 창과 숫자·골드가 같아요.
- 팔 수 있는 물고기 0마리면 버튼 꺼짐: 아무것도 안 골랐으면 「💰 고르면 팔기」, 잠긴 것만 골랐으면 「🔒 팔 수 없어요」.
- 「↩ 판에서 빼기 N」 은 그대로 잠긴 물고기도 세요 (빼기는 잠겨도 돼요).
- 고른 잠금 물고기 칸(`.msel.mslk`): 초록 대신 회색 테두리 · 그림 살짝 회색 · 왼쪽 위 ✓ 대신 🚫 · 아래 「판매 안 됨」 표 (글자는 ★N 표처럼 `--mbBk` 로 칸 크기에 맞춰 줄여요).
- 판매 모드에서는 손으로 잠근 물고기에도 🔒 표시 (자동 잠금 변이는 원래 보였어요). 참고: 손으로 잠근 물고기는 원래 합성 목록에 안 나와서 판에 거의 올라오지 않아요.
- 문구 「🔒 잠긴 물고기는 못 팔아요」는 360px 폰에서 잘려서 「🔒 팔 수 없어요」로 줄였어요.
