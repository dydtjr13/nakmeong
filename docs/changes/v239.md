# v239 — 🐢 새 탈것 「바다거북」 추가 (기존 거북이는 그대로)

- 날짜: 2026-11-27 (Asia/Seoul)

## 바뀐 점
- 상점 › 🚗 탈것에서 「거북이」 바로 아래에 **「바다거북」**을 새로 추가했어요. 기존 「거북이」(초록 · 8,000,000 골드)는 모양·가격·보유 상태 모두 그대로예요.
- 색상 4가지 (색마다 따로 사요)
  - 에메랄드 — 10,000,000 골드
  - 산호·옥빛 — 10,000,000 골드
  - 황금 전설 — 12,000,000 골드
  - 밤바다 오로라 — 12,000,000 골드
- 모양: 둥근 등딱지와 무늬 판, 가장자리 판, 등 위 담요와 방석 자리, 웃는 얼굴, 지느러미 발. 물 위에서는 물보라·물결 고리가 생겨요.
- 기능은 기존 거북이와 같아요: 땅에선 느릿느릿(속도 +10%), 물에 들어가면 헤엄(속도 +70%), 물 위에서 낚시 가능, 운하에서는 늘 헤엄.
- 테스트 기능 「🐢 거북이」가 켜져 있을 때 상점에 같이 보여요 (지금 실제 설정은 켜짐).
- 다른 유저의 바다거북은 가벼운 버전으로 그려서 버벅임을 줄였어요.

## 기술 메모
- 새 파일 `turtle-v2-v239.js` (`window.TURTLE_V2(색, {lite})`) — 기존 `TURTLE_C3`와 같은 userData(tick·mode·seat) 방식이라 거북이 코드를 그대로 써요.
- `game-v2.js`: `FLY.turtle2`, `FLYB.turtle2`(모듈이 없으면 기존 거북이 모양), `isTurK`로 거북이 두 종류를 같이 처리(속도·물/땅·낚시·운하), 상점 표시 조건, 다른 유저용 `vehMesh(k,1)` → lite.
- 삼각형: 내 거북이 약 13,700(땅) / 15,000(물), 다른 유저용 lite 약 5,100 / 6,100.
- 상점 썸네일은 미리 그려 둔 `img/veh/fly-turtle2-{emerald,coral,gold,aurora}.png`를 써요 (없으면 게임 안에서 그려요).
- 관리자 가격 설정(`vehCfg.pr.turtle2`)을 넣으면 네 색 모두 그 가격으로 바뀌어요.
