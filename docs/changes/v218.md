# v218 — 작은 창(PiP): 휴대폰 "이상한 창" 고침 · PC 크롬·엣지 탭 전환 자동 정리 · 기기별 안내

- 서버(Worker) 변경: **없음**
- 캐시: `game-v2.js?v218` (`nakmeong.html`) · 가이드 `site.js?v218`
- 파일: `game-v2.js` (작은 창 블록 `v174 🖼 작은 창` IIFE, 숨김 진행 블록 `NK_BG`), `nakmeong.html`, `guide-site/public/site.js`, `guide-site/public/index.html`

## 원인
1. **휴대폰 "이상한 창"**: 예전 코드는 창이 숨겨진 **뒤에**(`visibilitychange` hidden) 사용자 동작 없이 `video.requestPictureInPicture()`를 불렀어요.
   안드로이드 크롬·삼성 인터넷은 작은 창을 "영상 전체 화면 → 작은 창" 순서로 만드는데, 앱이 이미 뒤로 간 상태라 전체 화면 영상 창(이상한 창)만 먼저 뜨고, 홈을 한 번 더 눌러야 작은 창이 됐어요.
2. **PC 자동이 안 됨**: 크롬·엣지는 브라우저가 `mediaSession`의 `enterpictureinpicture`를 불러 줄 때만 사용자 동작 없이 작은 창을 열 수 있어요. 조건(크롬 공식 문서 + 크롬 156 실측):
   - **다른 탭으로 옮길 때만**. 창 최소화·다른 프로그램으로 전환은 크롬이 부르지 않아요 (리눅스 크롬 156 실측: 최소화 시 호출 0회).
   - 소리가 나는 미디어(배경음악 등)가 재생 중이고 최근 2초 안에 소리가 났어야 해요 (숨은 작은 창 영상은 소리가 없어서 조건이 안 돼요).
   - 사이트 설정 「자동 PIP」 허용, 또는 자주 미디어를 들은 사이트(MEI). 처음엔 크롬이 허용 여부를 물어요.
   - 예전 코드는 이 호출 외에 숨김 직후에도 직접 열어 보는 시도를 같이 해서, 기기에 따라 겹쳐 시도하거나 실패 안내만 떴어요.
3. `autopictureinpicture` 속성은 사파리가 실제로 동작시키지 않아요(인라인 영상). 아이폰은 전체 화면 영상만 홈에서 자동 작은 창이 돼요.

## 수정
- 숨김 뒤 직접 열기(`requestPictureInPicture` in `visibilitychange`) **삭제** → 휴대폰 이상한 창 원인 제거.
- `mediaSession` 핸들러를 한 번만 등록(`msInit`). 크롬·엣지가 부르면(`reason` 확인) 설정 「다른 탭으로 옮기면 자동」이 켜져 있을 때만 PC는 새 창(Document PiP), 아니면 영상 작은 창을 열어요. 꺼져 있으면 아무것도 안 함(크롬 142+ 브라우저 자동도 막힘).
- 숨은 영상에 `disablePictureInPicture` — 브라우저가 따로 작은 창·전체 화면으로 띄우지 않게, 우리가 열 때만 잠깐 풀어요. `autopictureinpicture` 속성 제거.
- 숨긴 뒤 작은 창이 열리면 숨김 진행(`__nkBgKick`)을 바로 시작 (예전엔 최대 5초 늦음).
- 자동이 안 됐으면 돌아왔을 때 기기별 안내를 한 번만(`S.pipTip_mob/pc/none`):
  - 휴대폰: "창을 내리기 전에 메뉴 › 작은 창"
  - PC 크롬·엣지: "소리 켠 채 다른 탭으로 옮길 때 자동 (처음엔 허용) · 최소화 때는 미리 버튼"
- 작은 창 설정 창: 자동 토글은 PC 크롬·엣지에서만 보여요. 휴대폰 안내·PC 안내를 나눠 표시. 아이폰 앱 안 브라우저(카톡·네이버 등)는 작은 창 대신 전체 화면 영상이 뜰 수 있어 버튼을 숨겨요.
- 디버그용 기록 `window.__nkPipLog` (최근 40줄).

## 실기기 확인 방법 (사용자)
1. 안드로이드 크롬/삼성 인터넷: 메뉴 › 작은 창 › 「지금 작은 창으로 보기」 → 바로 작은 창이 되는지, 홈으로 나가도 유지되는지. 버튼 없이 홈을 누르면 **아무 창도 안 뜨고**, 돌아오면 안내가 한 번 뜨면 정상.
2. 아이폰 사파리: 같은 버튼 → 작은 창.
3. PC 크롬·엣지: 소리(배경음악) 켠 채 다른 탭 클릭 → 작은 창 자동 (처음엔 주소창 쪽 허용 질문). 안 뜨면 주소창 자물쇠 › 사이트 설정 › 「자동 PIP」 허용.

## 남은 점
- 휴대폰은 브라우저 정책상 "내리기만 하면 자동 작은 창"이 불가 → 버튼 방식 (안드로이드 크롬이 앱 안 자동 PiP를 정식 출시하면 같은 핸들러로 동작할 수 있어요).
- 소리를 끈 PC 유저는 탭 전환 자동이 안 돼요(크롬 조건).
