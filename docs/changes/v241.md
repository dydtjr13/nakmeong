# v241 — 🛩️✈️ 새 전투기 2종 추가 (테스트 · 기존 전투기 그대로)

- 날짜: 2026-11-27 (Asia/Seoul)

## 바뀐 점
- 상점 › 🚗 탈것에 하늘을 나는 새 전투기 2종을 추가했어요. 기존 「전투기」(회색 · 남색 · 블랙 · 황금)는 모양·가격·보유 상태 모두 그대로예요.
- **🛩️ 오픈 전투기** (열린 조종석 · 캐릭터가 보여요)
  - 로열 에이스 — 12,000,000 골드
  - 크림슨 스텔스 — 12,000,000 골드
  - 오로라 스타파이터 — 14,000,000 골드
- **✈️ 버블 전투기** (유리 캐노피 안에 앉아요 · 캐릭터가 보여요)
  - 로열 골드 에이스 — 12,000,000 골드
  - 오로라 펄 — 14,000,000 골드
  - 크림슨 피닉스 — 12,000,000 골드
- 기능은 기존 전투기와 같아요: 하늘 날기(속도 +95%), 오르내리기, 기울어지며 날기, 엔진 불꽃, 「💥 미사일」 발사, 펫 자리, 다른 유저에게도 보임.
- 테스트 기능 「전투기」가 켜져 있을 때 상점에 보여요 (지금 실제 설정은 켜짐). 테스트 후 넣을지 뺄지 정해요.

## 기술 메모
- 새 파일 `jet-open-v241.js` (`window.JET_OPEN.build`) · `jet-bubble-v241.js` (`window.JET_BUBBLE.build`). 둘 다 재질별로 미리 합쳐서(`userData.slim=1`) 게임의 합치기 과정을 건너뛰어요. 삼각형 약 17,700.

- `game-v2.js`: `FLY.jetA` · `FLY.jetB`, `FLYB.jetA/jetB` (파일 오류 시 기존 전투기 모양), 기본 고도 20, 상점 표시 조건, 썸네일 각도, 펫 자리 `PRSLOT.jetA/jetB`.
