## 일반 유저에게 바뀐 점
- **장비 모자**: 밀짚 모자처럼 챙이 넓은 모자가 카드 양쪽에서 잘리던 문제를 고쳤어요. 카드 안에 그림 전체가 보이게 맞췄어요.
- **열기구**: 위쪽 풍선과 아래 바구니가 잘리던 그림을 다시 그려서, 카드와 큰 미리보기에서 전체가 보여요.
- **그 밖에 함께 고친 것**
  - 기린(뿔이 카드 위에 거의 붙어 있던 것), 바다거북(아래가 타이트하던 것)
  - 어항 10종: 뚜껑·받침이 잘리던 미리보기 그림을 다시 그렸어요. (안에는 예전처럼 예시 물고기가 있지 않아요)
- 낚싯대 설명줄 이모지가 좁은 휴대폰(412×915)에서 오른쪽으로 조금 잘리던 것도 정리했어요.

## 원인
- 열기구·기린·어항은 CSS가 아니라 **3D 썸네일을 그릴 때 카메라가 너무 가까워** 이미 잘린 그림이 저장되어 있었어요. (이전 v244는 `object-fit: contain`만 손봐서, 이미 잘린 원본은 그대로였습니다)
- 모자는 원본 PNG는 괜찮았지만, 카드 칸에서 그림이 가로로 꽉 차며 둥근 모서리에 챙이 잘렸어요.
