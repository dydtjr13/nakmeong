- 날짜: 2026-11-28 (Asia/Seoul)
- 버전: v249 (main에 모바일 알림 v248이 먼저 머지되어 +1)
- 사용자 요청: v247 이후에도 상점 이미지가 잘리거나 작거나 안 보인다는 제보. 야광 미노우 루어 잘림, 밀짚·탐험가 모자 오른쪽 잘림, 탈것이 너무 작음, 노 젓는 보트 이미지 미표시, 상점 밸런스표 끄기.
- 백업: `/workspace/nakmeong-backups/shop-thumb2-pre-20261128-1028.bundle`

## 일반 유저에게 바뀐 점
- **야광 미노우 루어**: 주둥이가 잘려 있던 원본 그림을 완성해서, 카드와 큰 미리보기에서 전체가 보여요.
- **밀짚 모자 · 탐험가 모자**: 오른쪽 챙이 잘려 있던 원본을 고쳤어요. 버킷햇·파나마 햇처럼 비슷하게 타이트하던 모자도 함께 정리했어요.
- **탈것**: v247에서 여백을 너무 많이 넣어서 그림이 작아 보였던 것을, 잘리지 않는 선에서 카드에 더 크게(여백 약 4%) 다시 맞췄어요.
- **노 젓는 보트**: 안 나오던 그림을 다시 보이게 했어요.
- **상점 밸런스표**: 일단 꺼 두었어요. (나중에 테스트 기능에서 다시 켤 수 있어요)

## 원인
- 야광 미노우·밀짚·탐험가 모자는 CSS가 아니라 **원본 PNG 자체가 투명 여백 안에서 이미 잘려** 있었어요. v247 픽셀 검사가 여백만 보고 0건으로 넘어간 이유입니다.
- 탈것은 v247의 AABB 14% 여백 + 느슨한 바운딩 박스 때문에 실제 그림이 카드에서 너무 작게 보였어요.
- 노 젓는 보트는 Kenney GLTF가 아직 안 불러온 채로 `flyThumb`이 빈 캔버스를 캐시하고, 그 때문에 PNG 대체 그림이 쓰이지 않았어요.
- 밸런스표는 관리자/오너에게만 보이던 탭이지만, 기본을 꺼 두라는 요청이어서 별도 플래그로 기본 끄기로 바꿨어요. 표 생성 코드는 그대로 둡니다.
