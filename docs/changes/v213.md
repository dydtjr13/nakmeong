## 무엇을 바꿨나

- 슈퍼 초월급 새 물고기 **부산 부캉이** (S05, 키 `st_bukang`)를 운하에 넣었어요. 시안은 B안 「밤항구 부캉이」예요.
- 이름은 「부산 부캉이」, 나오는 곳은 운하예요. 등불 혹등고래와 같은 자리에서 만나요.
- 공식 이모티콘·로고는 쓰지 않고, 흑상어의 생김새(둥근 주둥이, 등지느러미 사이 융기선, 청동 회색)와 북항 밤 불빛만 담았어요.

## 값 (운하 기존 슈퍼 초월과 비교)

등불 혹등고래(S02)와 맞춰 두었어요. 자동 낚시는 둘 다 안 나오고, 별도 미끼 조건은 없어요.

| | 등불 혹등고래 | 부산 부캉이 |
|---|---|---|
| 맵 | 운하 (`canal`) | 운하 (`canal`) |
| 확률 계수 `rate` | 25000 | 25000 |
| 실제 확률 (기본 `stRate` 300,000 기준) | 약 1/375,000 번 던질 때 | 약 1/375,000 번 던질 때 |
| 기본 골드 `base` | 90,000 | 90,000 |
| 크기 | 11.00~15.20m | 2.80~3.60m (실제 약 3m 흑상어에 맞춤) |
| 어항 효과 | 경험치 +5% | 골드 +5% |
| 자동 낚시 | 제외 | 제외 |
| 미끼 조건 | 없음 (운하에서 직접 낚시) | 없음 (운하에서 직접 낚시) |

- 운하에 두 종이 있어서, 예전처럼 `SP.find`(맵당 첫 종만)로 굴리면 부캉이가 안 나왔어요. 이제 같은 맵의 종을 각자 확률로 굴리고, 둘 다 나와도 하나만 골라요.
- 도감 칸은 5종을 보도록 줄을 바꿨어요.
