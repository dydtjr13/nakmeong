## 관리자 모드 (휴대폰)
- 360×640 · 390×844 · 412×915 에서 7묶음 · 하위 메뉴 29개를 검사해, 창 전체가 화면 밖으로 나가거나 본문이 가로로 밀리던 문제를 고쳤어요.
- 넓은 표(유저 찾기·지급·제재, 신고·도배, 아이템 복구, 밸런스, 펫·탈것 등)는 **표 안쪽만** 가로로 스크롤되거나, 칸이 4개 이상이면 **카드 줄**로 바뀌어요. 창 전체는 화면 안에 남아요.
- 필터 칸·버튼 줄은 좁은 화면에서 다음 줄로 내려가고, 날씨 종류 버튼도 줄바꿈돼요.
- 검색 칸, 헤더, 저장 바는 화면 폭에 맞춰 줄바꿈돼요.
