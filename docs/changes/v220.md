## 사용자 입장에서 달라진 것
- 오른쪽 위 메뉴(≡) 바로 왼쪽에 **화면 설정 버튼**이 생겨요. 메뉴 버튼과 같은 크기·모양·높이예요.
  - 지금 모드가 아이콘으로 보여요: 보통 창 = 모니터 · 전체화면 = 네 모서리(주황) · 작은 창 켜짐 = 작은 창 그림(주황) — 주황일 때 오른쪽 위에 작은 주황 점.
- 누르면 **화면 설정 창**이 화면 가운데 떠요.
  - 왼쪽 「전체화면」(지금 게임 화면 미리보기) · 오른쪽 「작은 창」(다른 창 위에 작은 창이 떠 있는 그림) 중 고르고, 아래 큰 주황 버튼으로 적용해요.
  - 지금 쓰는 모드 카드에는 「지금」 표시, 버튼 글자는 상황에 맞게 바뀌어요: 「전체화면으로 보기」 / 「전체화면 끄기」 / 「작은 창 띄우기」 / 「작은 창 닫기」 / 「작은 창 닫고 전체화면으로」 / 「전체화면 끄고 작은 창으로」.
  - 아래 「작은 창 설정」 글자를 누르면 기존 작은 창 설정 창(자동으로 켜기 · 보여 줄 화면)이 그대로 열려요.
  - 바깥(어두운 곳) · × · Esc 로 닫혀요. 창이 열려 있는 동안 화면 설정 버튼은 숨어요.
- 전체화면을 못 쓰는 브라우저(아이폰 사파리 등)는 카드에 이유가 적혀 있고, 누르면 안내만 떠요 (예: 「아이폰: 공유 › 홈 화면에 추가로 열면 주소창 없이 쓸 수 있어요」 — 기존 `NK_FULL.note()` 문구).
- 작은 창을 못 쓰는 브라우저·기기(또는 운영자가 작은 창 기능을 끈 경우)는 「작은 창」 카드가 흐리게 잠기고 「이 브라우저·기기에서는 작은 창을 쓸 수 없어요」라고 보여요.
- 좁은 휴대폰(가로 400px 미만, 예: 360×640)은 위쪽 정보 줄(레벨·골드·선물) 사이 간격만 6→3px, 알약 좌우 여백만 8→6px로 줄여서 버튼 자리를 만들어요. 글자 크기는 그대로.

## 코드
- `game-v2.js` 작은 창 모듈 바로 뒤에 새 모듈(v220 🖥 화면 설정) 추가.
  - 작은 창: 기존 진입 경로 `NK_PIP.open()`(= 메뉴 › 작은 창 › 「지금 작은 창으로 보기」와 같은 함수) 그대로 호출. 닫기는 `NK_PIP.close()`.
  - 작은 창 모듈에는 읽기용 `NK_PIP.ok`(작은 창 쓸 수 있나)·`NK_PIP.act()`(켜져 있나) 두 개만 내보내도록 추가 — 작은 창 동작·설정·문구는 v219와 같아요.
  - 전체화면: 기존 `NK_FULL.go()`(Fullscreen API, `webkit` 포함) / 끄기 `document.exitFullscreen`. 전체화면 중에 작은 창을 고르면 전체화면을 먼저 끄고 작은 창을 열어요.
  - 위치: 메뉴 버튼(휴대폰 `#bMore`, PC `#mSys`)의 위치·크기·모서리를 0.4초마다 읽어서 왼쪽 6px 간격에 붙여요. 휴대폰은 위쪽 정보 줄(`#mStat`) 최대 너비를 버튼 왼쪽 8px까지로 맞춰요.
  - 게임 시작 전·다른 창(모달)이 열렸을 때·메뉴가 펼쳐졌을 때는 버튼을 숨겨요.
