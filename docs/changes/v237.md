# v237 — 🛸 네온 UFO 새 탈것 추가 (기존 UFO는 그대로)

- 날짜: 2026-11-27 (Asia/Seoul)

## 바뀐 점
- 상점 › 🚗 탈것에 하늘을 나는 **「네온 UFO」**를 새로 추가했어요. 기존 「UFO」(은빛 원반 · 파스텔 꼬마)는 모양·가격·보유 상태 모두 그대로예요.
- 색상 3가지 (색마다 따로 사요)
  - 펄 실버 + 민트 네온 — 30,000,000 골드
  - 코스믹 네이비 + 골드 · 오로라 불빛 — 35,000,000 골드
  - 파스텔 — 30,000,000 골드
- 모양: 두 층으로 나뉜 부드러운 원반, 빛나는 테두리 링, 차례로 빛나는 불빛 24개, 큰 유리 돔(캐릭터 머리가 돔을 뚫지 않아요), 앞쪽이 열린 조종석, 홀로그램 계기판, 안테나, 아래 반중력 코어와 도는 빛 고리, 날 때 수면에 생기는 빛 고리.
- 기능은 기존 UFO와 같아요: 하늘 날기(속도 +120%), 아래로 끌어당김 빛, 「🛸 빨아들이기」 버튼, 다른 유저에게도 보임.
- 테스트 기능 「🛸 UFO 탈것」이 켜져 있을 때 상점에 같이 보여요 (지금 실제 설정은 켜짐).

## 기술 메모
- 새 파일 `vehicles-ufo2.js` (`window.NK_UFO2.build/tick`) · `game-v2.js`에 `FLY.ufo2`, `FLYB.ufo2`, UFO 불빛 훅에서 `NK_UFO2.tick` 호출, 빨아들이기 조건에 `ufo2` 추가, 상점 표시 조건에 `ufo2` 추가.
- 앉는 자리 `[0,.13,-.04]` · 배율 1.75 · 삼각형 약 13,800 · 메시 16개 (날 때 빛 기둥·수면 고리 포함 18~19개). 재질·텍스처는 색마다 한 번만 만들어 공유.
- 상점 썸네일 `img/veh/fly-ufo2-{pearl,cosmic,pastel}.png`.
- 관리자 가격 설정(`vehCfg.pr.ufo2`)을 넣으면 세 색 모두 그 가격으로 바뀌어요.
