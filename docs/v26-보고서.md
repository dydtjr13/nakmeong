**UI 편집 단축키**

| 조작 | 동작 |
|---|---|
| 끌기 | 자석 정렬(다른 창의 가장자리·가운데, 화면 가장자리·가운데, 6px). 붙을 때 분홍 정렬선이 보여요 |
| Shift + 끌기 | 가로나 세로 한 방향으로 고정하고, 맞는 정렬선을 모두 보여줘요 |
| Ctrl(⌘) + 끌기 | 자석을 끄고 자유롭게 미세 조정해요 |
| 방향키 / Shift + 방향키 | 1px / 10px씩 움직여요 |
| Ctrl + Z / Ctrl + S | 되돌리기 / 저장(브라우저 저장 창은 막아요) |
| 테두리에 마우스 올리기 | 크기 조절 커서가 나와요. 비율을 지키며 60~160% 사이로 바꿔요(5% 단위, Ctrl을 누르면 자유롭게) |
| 편집 막대 제목 끌기 | 편집 막대 자체를 옮겨요 |

| 낚싯대 | 등급 | 빠른입질 | 대어 | 희귀어종 | 랜덤 옵션 | 초월 물고기 | 착용 레벨 | 얻는 곳 |

- **코드에 있던 실제 초월 확률:** `D.TX.p = 0.000066` = 0.0066%(약 1/15,152). 행운 보정은 최대 ×1.8이에요.
- 심해·천룡·화룡을 장착하면 기본 확률이 **0.066%**(10배)가 돼요(`D.TX.rodP`). 행운 보정(최대 ×1.8)은 그대로 적용돼요.
- **신화 상자에서 낚싯대가 나올 때(20만 번 굴림):** 별빛 47.6%, 은하수 25.6%, 용왕 22.9%, 심해 2.0%, 천룡 1.0%, 화룡 1.0%.
- **전설 상자:** 별빛 37%, 황금 30%, 상위 대체 20%, 은하수 11.8%.
- 신화 상자는 전체 상자의 0.1%이고, 상자에서 낚싯대가 나올 확률은 25%예요. 그래서 천룡 하나는 상자 약 40만 개당 1개꼴이에요. **아주 드물게** 만들었어요.
- 버그도 하나 고쳤어요. 신화 상자에서 낚싯대가 계속 아래 단계로 밀려 벚꽃까지 내려가던 문제예요. 이제는 상자 풀 밖으로 한 번만 내려가요.
- 진행도 계산은 낚싯대가 늘어도 용왕을 100% 기준으로 유지해요.

## 3. 적용하지 않은 것과 이유

- **10개 합성 정식 UI:** 시안(9번)이 아직 정해지지 않았어요. 그래서 기존 자리에 진행 버튼만 넣었어요. v25 계획에 있던 “추가옵션 하나 골라서 물려받기”와 “강화석 50% 돌려주기”는 UI가 필요해서 빼고, 대신 **★0·+0 재료만** 받도록 해서 손해가 없게 했어요.
- **러버덕 라이선스 주의:** JDSherbert “3D Rubber Duck Asset Pack”(itch.io)은 상업·비상업 이용이 가능하고, 작가 표기가 필수예요. 원본 파일은 저장소에 넣지 않았어요. 변환한 꼭짓점 데이터만 넣었어요(`duck-mesh-v26.js`, 파일 머리에 표기). 크레딧은 설정 화면과 README에 있어요. 다만 라이선스에 “사전 동의 없이 수정·재배포 금지” 문구가 있어요. 공개 저장소에 변환 데이터를 올리는 게 이 문구에 걸릴 **위험이 조금 있어요.** 걱정되면 작가에게 허락을 받거나, 직접 만든 로우폴리 오리로 바꿀 수 있어요(반나절 정도).
- **운영자 공지와 레벨 알림:** 둘 다 화면 위쪽 가운데에 떠요. 동시에 뜨면 겹칠 수 있어요(기존 배치예요). 편집 모드에서 하나를 옮겨 저장하면 해결돼요.
