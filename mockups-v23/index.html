2모바일 자동 낚시 버튼: 낚시 버튼에 붙인 원형 배치

A4는 낚시 버튼과 거리가 멀었어요. A5~A8은 모두 버튼끼리 4px 이상 떨어져 겹치지 않으면서 낚시 버튼 둘레에 원형으로 붙였어요 (390×844 기준 계산).

시안배치낚시 버튼과 거리메모
A5 둘레 반지5개를 반지름 76px 원 위에 37.5° 간격12px가장 동그랗게 보임. 아래쪽 가방이 화면 끝에 가까움
A6 작은 버튼 반지버튼 40px, 반지름 86px 30° 간격24px여백 넉넉, 버튼이 조금 작아짐
A7 위성형 추천자동 버튼(36px)만 낚시 버튼에 바짝 붙이고, 나머지 4개는 바깥 원4px자동 = 낚시의 짝이라 의미상 가장 자연스러움. 켜지면 초록 링
A8 두 겹 부채꼴안쪽 3개(자동·상점·도감) + 바깥 2개(가방·어항)8px자주 쓰는 버튼을 안쪽에

3모바일 가용 높이 · 날씨 패널과 낚시 카드 겹침

원인: 모바일 브라우저는 위 주소창과 아래 툴바가 화면을 차지해서, 같은 폰(390×844)이라도 게임이 쓸 수 있는 높이가 약 660px까지 줄어요. 그만큼 날씨 패널과 낚시 카드가 겹쳐요.

방법v23 적용효과 · 한계
전체 화면 API (requestFullscreen)적용안드로이드 크롬·삼성 인터넷·엣지: 시작 버튼을 누를 때 전체 화면으로 바뀌어 주소창과 툴바가 사라져요 (설정에서 끌 수 있음). 아이폰 Safari는 웹 페이지의 전체 화면을 막아 둬서 불가해요 (동영상만 가능).
홈 화면에 추가 (웹 앱 manifest · display: fullscreen)적용아이폰·안드로이드 모두 홈 화면 아이콘으로 열면 주소창 없이 실행돼요. 아이폰에서 사실상 유일한 '최대 화면' 방법이에요.
viewport-fit=cover + safe-area적용노치·홈 바 영역까지 배경을 채우고, 버튼은 안전 영역 안쪽에 둬요.
visualViewport 높이 감지적용실제 남은 높이를 재서 700px 미만이면 body에 표시를 달아 둬요 (아래 배치 시안을 바로 붙일 수 있게).
스크롤로 주소창 숨기기안 함요즘 브라우저는 페이지가 실제로 스크롤될 때만 주소창을 줄여요. 게임 화면은 고정이라 효과가 없고, 오히려 화면이 흔들려요.

결론: 어떤 브라우저든 강제로 최대 화면을 만드는 방법은 없어요. 안드로이드는 전체 화면 API로, 아이폰은 홈 화면 추가로 해결하고, 남은 경우를 위해 아래처럼 높이가 줄어도 안 겹치는 배치가 필요해요.
